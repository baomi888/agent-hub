## 五、这两天踩的坑

| 坑 | 现象 | 真因 |
| --- | --- | --- |
| **CSS 变量在声明处替换** | 番茄钟只换了进度条，按钮还是金 | `.campus-shell` 上写 `--campus-btn-solid: var(--accent-ink)`，在那里就算成字面量了；子面板改 `--accent-ink` 不会重算 → 每个面板必须重声明 `--campus-btn-solid` |
| **断言假通过（1）** | 「其他五面板圆角 16px」一直过 | 点 tab 后在同一次 evaluate 里读 `.campus-card`，读到的还是旧面板 → 改逐面板点 + 等 350ms + 断言「旧面板已卸载」 |
| **断言假通过（2）** | 优化回归把一组刷成第 8 轮回炉 | 用「包含 认识」点按钮，点中的是「不**认识**」 → 精确匹配 `trim() === text` |
| **截图误伤** | 压缩脚本把已提交的课表截图也压了 | 目录参数写死没加范围 → `git checkout --` 逐个还原 11 张 |
| **构建被拦** | `npm run build` 报 safe-delete 拒绝 | dev server 占着 `.next` → `TaskStop` 后 `mv .next` 出项目再重建 |
| **`git push` 长期不通** | `CONNECT tunnel failed, 502` | 出口代理拦 github.com:443；`api.github.com` 通 → Git Data API |

**最贵的一个坑是第一个**：它不是手误，是 CSS 自定义属性的语义 —— 变量在**声明它的元素**上就代入值了，子元素改上游变量不会回流。这条已写进 `docs/05` 和两批报告，下次再加身份色不会再踩。
