## 1. 为什么每个赛事要写「两个时间」

这是本批唯一一个我主动加的设计，理由值得先说清。

「什么时候比赛」和「什么时候报名」是两件事，而**信息差主要发生在报名阶段**——多数人不是不知道有这个比赛，是知道的时候报名已经截止了。

例：

- 数学建模竞赛 9 月 10 日开赛，但报名 8 月中旬就截止，且要交 300 元/队
- 电子设计国赛 8 月，省赛 7 月底，校赛选拔往往 4–5 月就走完了
- 大挑国赛 11 月，但校赛 4 月就开始了

只标「比赛时间」的年历表，等于告诉学生一件已经来不及的事。所以每条存**两个区间**：

```
招募/报名窗口  ──────▶  比赛/决赛时间
```

年历表上两个时间点都会出现，用同一种颜色、不同浓淡区分（报名=浅，比赛=实）。

## 3. 分类体系（8 类）

归类依据**参赛作品的主要形态**，不按主办单位。每项只给一个**主类**（决定色条），可以带副标签。

| # | 分类 | 判定规则 | 代表赛事 | 色 |
| --- | --- | --- | --- | --- |
| 1 | 创新创业 | 交的是项目/商业计划，看落地与商业价值 | 互联网+、大挑、小挑、三创赛 | 赤陶 `#C25A2E` |
| 2 | 计算机与 AI | 交的是代码、算法、数据模型、智能系统 | ACM、蓝桥杯、计算机设计、AI 算法精英 | 蓝 `#4E7EA8` |
| 3 | 电子信息与智能制造 | 交的是硬件、电路、芯片、机器人、整车 | 电子设计、智能汽车、机器人大赛、集成电路 | 金 `#C8892A` |
| 4 | 数理与学科基础 | 数学、物理、化学、生物、地学、力学等基础学科 | 数学建模、统计建模、物理实验、金相 | 草绿 `#6F8A4E` |
| 5 | 语言与人文 | 外语能力、中文表达、文学创作 | 外研社国才杯、21 世纪杯、中华经典诵写讲 | 赭红 `#A8574E` |
| 6 | 经管与商科 | 市场、金融、会计、管理、物流、电商 | 市场调查、商业精英、金融科技、沙盘 | 紫 `#7A6BA8` |
| 7 | 设计与建筑 | 视觉/工业设计、数字艺术、建筑规划 | 米兰设计周、未来设计师、BIM、结构设计 | 青 `#4E8A84`（新增第 7 色） |
| 8 | 综合与其他 | 跨类难归、强专业壁垒（医学、物流、公益） | 医学技术技能、物流设计、中美创客 | 灰 `#8A8375` |

**为什么是这 8 类**：你举的 AI、英语两个例子其实是「按学科方向」切的。沿着同一条轴切下去，84 项目录自然会分成上面 8 堆——计算机与 AI、电子信息、数理基础、语言人文、经管商科、设计建筑，剩下不好归的进「其他」。这样切的好处是**学生按自己的专业就能定位到 1–2 类**，不用逐个看 50 项。

**多标签的处理**：数学建模主类是「数理基础」，副标签可带「AI」；广告艺术大赛主类是「语言与人文」，副带「设计」。筛选时按主类分栏，按标签可搜。

## 5. 广东省省赛怎么挂

广东省有官方的「本科高校大学生十大学科竞赛」名单。它分两种，处理方式不同：

**A. 全国赛的广东分赛（5 项）→ 不单列，挂在对应全国赛事下**

| 省赛 | 挂在 |
| --- | --- |
| 全国大学生数学建模竞赛广东省分赛 | 数学建模 |
| 全国大学生电子设计竞赛广东省分赛 | 电子设计 |
| 全国大学生广告艺术大赛广东省分赛 | 广告艺术 |
| 全国大学生英语演讲比赛广东省分赛 | 21 世纪杯 |
| 全国大学生工程训练综合能力竞赛广东省分赛 | 工程实践与创新 |

理由：它本来就是全国赛的一环，单独列会让同一条赛事在年历表上出现两次，反而更乱。详情页里会写明「省赛阶段：X 月，广东省赛由 XX 承办」。

**B. 广东自己办的赛事（5 项）→ 单列条目**

| 赛事 | 时间（往年规律） | 适合谁 |
| --- | --- | --- |
| 广东省大学生计算机设计大赛 | 3–5 月报名 · 5–6 月比赛 | 计算机/数媒 |
| 广东省高等学校大学生工业设计大赛 | 6–7 月报名 · 7–8 月比赛 | 工业设计 |
| 广东省本科高校师范生教学技能大赛 | 4–6 月 | 师范类 |
| 广东省工科大学生实验综合技能竞赛 | 3–5 月 | 工科 |
| 广东省大学生生物化学实验技能大赛 | 4–6 月 | 生物/化学 |

这 5 项单列，分类分别归到「计算机与 AI」「设计与建筑」「语言与人文（师范）」「电子信息」「数理基础」。

合计 **65 条赛事**（60 + 5 项省级独有）。

## 7. 数据结构（供你判断复杂度）

```ts
/** 举办周期 */
type Cycle = "annual" | "odd" | "even" | "biennial";

/** 一条赛事 / 考试 */
interface EventItem {
  id: string;
  name: string;
  /** contest 赛事 / cert 证书考试 / exam 升学就业（考研、国考、省考） */
  kind: "contest" | "cert" | "exam";
  category: CategoryId;        // 主类，决定色条
  tags?: string[];             // 副标签，如 ["AI"]、["英语"]
  /** 报名窗口：月份区间，1–12 */
  signup?: { from: number; to: number; note?: string };
  /** 比赛 / 考试：月份区间 + 可选确切日 */
  contest: { from: number; to: number; exact?: string };
  cycle: Cycle;
  /** 周期为 biennial 时，哪些年份办 */
  cycleNote?: "odd" | "even";
  intro: string;               // 一句话性质
  fitFor: string;              // 适合哪类学生
  require?: string;            // 组队 / 门槛
  officialUrl?: string;
  /** 已知的当年确切时间，标注来源年份 */
  verified?: { year: number; text: string };
}
```

存储的只有用户自己的状态，赛事数据是静态文件：

```ts
interface EventUserState {
  /** 已完成 / 不感兴趣，从年历表隐藏 */
  done: Record<string, "attended" | "passed" | "skip">;
  /** 自定义置顶提醒 */
  pins: { id: string; note?: string }[];
  grade: 1 | 2 | 3 | 4 | null;
}
```

键名：`campus.events.state.v1`（按现有约定挂在 `CAMPUS_KEYS` 下）。

| 8 | 「随实时文件动态调整」 | **构建前自动同步官网公告，只取标题与链接，不改日期** | `scripts/sync-events.mjs` 挂在 `prebuild`，写 `public/data/events/notices.json`；详情页显示「官网最新公告 · 自动同步 X」；5 站可抓、3 站是 JS 壳（挑战杯/互联网+/蓝桥杯）抓不到。**从公告正文抠日期需要后端 + 逐站解析，不在本批范围** |
| 9 | 点开日期该显示什么（2026-11-22） | **只显示这一天** | 原先把「本月其余 N 件（只有月份精度）」也摊进每一天，点 11 月任意一天都会倒出二十多件与那天无关的东西。这些条目根本没核实到日，进某一天的窗口就是假精确 —— 它们留在「本月清单」与日历上方「本月窗口」条里 |
| 10 | 「不感兴趣」的入口（2026-11-22） | **日历上直接点，不必先进详情** | 右栏清单每行一个 26px 圆形「×」，当天弹层里每行一个「不感兴趣」；收走后底部弹一句回执并指回「我的」。状态仍走 `marks[id] = "skip"`，不另存一套「隐藏」字段 —— 两套状态立刻会长出两份对不上的清单 |
| 11 | 新用户不知道这工具在干什么（2026-11-22） | **首次进入弹一次使用说明** | 四条用法 + 一句「只破信息差、不代办报名」的边界说明；`introSeen` 并入 `campus.events.state.v1`（不另开 storage 键，少一处「清了一个没清另一个」），标题右侧「使用说明」可随时重开 |

> 第 3 条定的「默认关」是刻意的：自动隐藏内容属于替用户做决定，
> 而年历表的价值恰恰是「原来还有这个」。宁可多两行，也不要让人以为大四什么都参加不了。
