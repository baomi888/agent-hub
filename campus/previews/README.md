# 双端体验页

看校园工具集在**电脑**和**手机**上分别长什么样，两边都能直接点。

## 怎么打开

1. 先起前端（项目根目录）：`cd frontend && npm run dev`
2. 浏览器打开 `campus/previews/dual.html`

默认指向 `http://localhost:3000/tools`。换地址加参数：`dual.html?url=http://localhost:3000/tools`。

## 能做什么

| 操作 | 说明 |
| --- | --- |
| 并排 / 只看电脑 / 只看手机 | 右上角切换；窄屏下自动改为上下排列 |
| 1440 / 1280 / 1024 | 换电脑视口宽度，看断点怎么变 |
| **点一下画面上的「点击开始操作」** | 进入操作态，这时才能点标签、建任务、开计时 |
| Esc / 点页面空白 / 「操作中 · 点此退出」 | 退回「只看」态，滚轮还给这页 |
| 重新加载 | 一端改了数据、另一端没跟上时用 |

> 为什么要点一下：画面上默认盖一层遮罩，iframe 是 `pointer-events: none`。
> 不这样的话滚轮停在画面上会被 iframe 吃掉，整页就滑不动了（0.5.3 之前踩过这个坑，
> 当时的错法是反过来把整页锁死，更糟）。

## 两端的差别在哪

- **≤720px**：标签栏从一行六个换成 2×3 网格（横滑会切掉最后两个工具）
- **≤560px**：主按钮占满整行；状态条文字占一行、按钮落到下一行右侧
- **手机 1:1、电脑按宽度缩放**：电脑端布局仍按 1440 排版，缩放不影响断点判定

## 注意

- 两端 iframe 同源，**共用同一份 localStorage**。一边新建了任务，另一边刷新才看得到 ——
  真实手机 + 电脑也是这个行为。
- 这个目录是验收工具，不进构建产物。
