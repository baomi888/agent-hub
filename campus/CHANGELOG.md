# 校园工具集 · 变更记录

> 只记本板块的变更，主站整体变更见仓库根目录 `CHANGELOG.md`。
> 版本号与 `VERSION` 文件严格一致；日期格式 `YYYY-MM-DD`。

## [0.2.0] - 2026-10-31

### 新增

- 番茄钟（`tools/pomodoro/`）：改时间戳计时，切标签页回来不掉拍；新增「今日已完成」持久化
  （旧版只放内存，刷新归零）。
- 课程表（`tools/schedule/`）：周视图 + 全屏 + 学期一览；周次条可前后翻、可直接选周；
  导入/导出「小律同款」JSON；手动添加与点块删除；学期设置支持「开学日期」或「今天是第几周」两种填法。
- 单词卡（`tools/words/`）：按级别分组（四级 4543 / 六级 2118），复习轮只练没记住的词，
  支持空格/方向键；词库加载失败时用内置 39 词兜底并明示。
- 倒计时（`tools/deadline/`）：增删改查 + 行内反复编辑，≤7 天标红、过期显示「已逾期 N 天」；
  页面常驻时每分钟重算剩余天数。
- 群抽签（`tools/draw/`）：名额、模拟名单、开奖公示（中签/未中分列）、随机点名。
- 逻辑层补齐 `logic/pomodoro.ts`、`logic/words.ts`、`logic/deadline.ts`，
  `logic/schedule.ts` 增加节次解析、分层布局、导入解析、旧数据迁移。
- 板块样式补齐五个工具的类，全部走全局令牌，`.dark` 自动适配。

### 变更

- `ToolNav` 六个工具 `migrated` 全部置为 `true`，占位组件 `PendingTool` 移除。
- 抽签名单解析改为**按行**切分（旧版口径），`Li Ming` 这类带空格的英文名不再被拆成两个人；
  仅在整段无换行且含逗号/顿号时才按分隔符切。
- 打开课表默认停在**当前教学周**（旧版仅首次进入如此，之后沿用上次翻到的周次）。

### 校验

- 逻辑自检 47 项全部通过：节次/周次解析、v1 数据 day 回拨、重叠课次分栏、
  按周筛选、词卡两个分支均前进、抽签中签与未中互补、日期本地零点解析。
- 旧版 v1 课表数据（`day = dayOfWeek % 7`）迁移后整体回拨一天，与旧版 10-29 的修复一致。
- `npx tsc --noEmit` 零错误；板块范围 `eslint` 零问题；`npm run build` 通过。

### 说明

- 线上入口**仍是** `/tools.html`，`TOOLS_URL` 未改。切换属于 S2，单独提交便于回滚。
- 深色主题依赖全局令牌自动生效，**未做逐像素对比度实测**，列为待评审项。
- 番茄钟完成提示由 `alert()` 改为页面内文案，不再弹阻塞对话框。

### 已知问题

- 课表不全屏时在窄屏需要横向滚动（与原版一致），未做移动端手势优化。
- 单词卡若一直点「不认识」，同一词会在复习轮里反复出现（与旧版一致，属设计行为）。

## [0.1.0] - 2026-10-31

### 新增

- 建立板块独立分区：`campus/`（治理区）+ `frontend/src/campus/`（代码区）+ 路由薄壳。
- 新增板块治理文档：边界与架构、本地存储契约、审核验收清单、开发提交流程。
- 新增板块版本号与独立变更记录机制，与主站版本解耦。
- 归档原型基线 `campus/prototypes/校园工具集_v1_原型_20261029.html`。
- 存储层收口 `storage/`：统一「新键 → 旧键 → 迁移 → 回写」通道，旧键保留不删。
- 纯函数层 `logic/`：GPA 换算与汇总、抽签（Fisher-Yates）、课表周次与星期归一。
- GPA 分析完成迁移（`tools/gpa/`），作为其余工具的参考实现。

### 校验

- GPA 换算表与旧版 `tools.html`（第 826–836 行）逐值比对通过，
  覆盖 59/60/63/64/67/68/72/75/78/82/85/90 等边界。
- 示例数据核算：GPA 3.27、加权均分 83.4、总学分 17，与旧版一致。
- 旧数据迁移（字符串字段、空成绩、缺字段）验证通过。
- `npx tsc --noEmit` 零错误。

### 说明

- 本版**未改动线上实现**。用户此刻访问的仍是 `frontend/public/tools.html`，
  入口常量 `TOOLS_URL` 保持指向 `/tools.html`，零行为变更、零回归风险。
- 新增路由 `/tools` 作为新实现的落脚点，当前为骨架页，未接入导航。

- 132 KB 单文件无模块拆分、无测试。
