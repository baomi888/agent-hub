# 审核报告目录

这里存放校园工具集的**每一份**审核报告。一份功能交付 = 一份报告，不允许合并成一份写。

## 规则

1. **命名**：`YYYY-MM-DD_<一句话主题>.md`
   - ✅ `2026-11-02_gpa工具按学期筛选.md`
   - ❌ `审核.md`、`review1.md`、`2026-11-02.md`
2. **来源**：复制 `TEMPLATE.md` 再填，不要自创格式。
3. **时机**：功能开发完成、自测通过后写。写之前先过 `docs/03_审核与验收清单.md`。
4. **审核通过前不推送**：报告先留在本地（本地 commit 可以，防丢失），
   等负责人通过、开发者授意上传后，才随代码一起推到 `school-tools`。
5. **归档不删**：被打回的旧报告保留，重写新的一份，便于回溯「打回过什么」。

## 与代码的关系

报告里的「改动文件」必须与本次提交的实际文件一致。
评审时可以对照 `git show --stat <commit>` 检查，对不上说明报告写虚了。
