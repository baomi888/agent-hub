## 1. 需求

原话：「那两个不要是并列的，是上下的，然后展开的时候不会影响到。」

两件事：**排布改上下**、**展开不推挤任何东西**。第二条才是关键 —— 竖排之后如果让展开区跟着被点的那一行走，
就会出现「点上面那个，下面那个被顶下去」，正好是「影响到」。

## 2. 改了什么

| 位置 | 改动 |
| --- | --- |
| `PomodoroTool.tsx` | `.campus-pomo-entry-row`（两列 grid）→ `.campus-pomo-entry-group`（单列块）；两个按钮直接作为组的子元素 |
| `campus.css` | 卡片边框 / 圆角 / 阴影从按钮移到分组；首尾行各拿自己的圆角；中间那条用 `inset 0 1px 0 var(--line)` 当分隔线 |
| `campus.css` | 展开态：底色 `--fill-3` + `inset 3px 0 0 var(--accent)` 左侧强调条 + 箭头 `rotate(90deg)` |
| `EntryFold.tsx` | 滚动锚点从整个 section 改为标题行（见第 4 节） |

按钮本身不再有 `border` / `box-shadow` / `border-radius`，只有 `background: transparent` 与 hover 底色。
这样组是一块卡片、两行是卡片里的两行，不是两个独立胶囊叠在一起。

## 3. 为什么展开区放在「组的下方」而不是「被点行的下方」

这是本次唯一的实质决策。

| 方案 | 点第一行 | 点第二行 | 问题 |
| --- | --- | --- | --- |
| 内容跟在被点行下面 | 内容出现在两行之间 | 内容出现在最下面 | **第二行被顶下去**，两行位置随点击变化 |
| 内容固定在组下方 | 位置不变 | 位置不变 | 点第一行时，中间隔着一行按钮才开始正文 |

选后者。理由：用户要的是「不影响」。而且手机竖屏下按钮组只占 96px，
隔一行的距离不影响阅读；但位置跳动是每次点击都会发生的。

代价写在这里：点第一行时，标题行与按钮组之间会隔着第二行。这是刻意的交换。

## 4. 修正上一版的滚动行为

0.5.5 对**整块**展开区调用 `scrollIntoView({ block: "nearest" })`。
统计面板 600px+，比视口还高，`nearest` 在这种情况下会尝试把它整个带进来，
实测把页面滚了 209px（桌面）/ 447px（手机），**刚点的那行按钮被推出视口上方**。
这本身也是一种「影响到」。

改成锚定**标题行**（34px）：只把标题行带进视口，剩下的交给用户。
实测滚动增量 0（两种屏幕、两种展开状态都是 0），按钮 y 坐标一字不变。
