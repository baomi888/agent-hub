## 1. 做了什么

三件事，都是围绕「番茄钟真正能用」补的：

| # | 内容 | 用户看到的变化 |

| 1 | 标签图标恢复 | 每个标签前重新出现那个小图标（GPA 是柱状图、番茄钟是番茄……） |
| 2 | 提示音 | 25 分钟结束时除了弹窗，还会响一声；有 5 种音色可选，能调音量，也能换成自己的音频 |

## 2. 为什么做

原话：「恢复原来每个标签前的图标。平滑切换不要改变。同时，所有优化都要适配双端。加上提示音，但不要太刺耳，舒缓提醒，可以搜索主流上的番茄钟音效设计，并且可以用户自主挑选（多设置几种，或是和可以选择链接歌单，自行连接设计）」

逐条对应：

- **图标**：0.2.0 迁移时只搬了文字标签，旧版的 SVG 留在了 `tools.html` 里。
- **提示音**：只有弹窗时，人离开电脑就完全错过。声音是第二条提醒通道。
- **不刺耳**：提示音响在「刚结束 25 分钟专注」的瞬间，人对突然的高频最敏感。参考了主流做法（三音上行琶音、
  渐强、自然音色），也参考了「渐进式增强以减少惊吓感」这条经验。
- **自主挑选**：内置 5 种 + 静音 + 自定义，覆盖「图书馆要小声」「宿舍要能叫醒」两种极端。
- **双端**：手机上真正的坑不是布局，是 iOS 输入框聚焦自动放大、底部安全区、触控热区。

## 4. 提示音的设计口径

### 4.1 为什么自己合成，不打包 mp3

| 方案 | 体积 | 版权 | 可调性 |
| --- | --- | --- | --- |
| 打包 5 个 mp3 | ≥ 300 KB，还要处理缓存与跨域 | 要么买授权，要么找 CC0 | 固定，改音量只能调 gain |
| **Web Audio 合成** | < 1 KB 代码 | 不涉及采样 | 频率、时长、泛音、低通都能按设备调 |

副作用是首次播放需要 `AudioContext`，而浏览器要求它必须在用户手势里创建。处理见 4.3。

### 4.2 「不刺耳」的三条硬约束

不是形容词，是写进代码的检查项：

1. **不用方波 / 锯齿波** —— 谐波丰富，是「尖」的主要来源；只用正弦与三角波（自检里有断言）。
2. **一律低通**，截止 2.4–7 kHz，削掉 4 kHz 以上的高频毛刺。
3. **起音 12 ms 渐入、尾音 1.5–3 秒指数衰减**，单音峰值增益 ≤ 0.3（自检断言），
   整体再乘音量并做 120 ms 渐强 —— 避免「突然一下」。

### 4.3 会自动播放被拦吗

浏览器的规则是：`AudioContext` 必须在用户手势里创建或恢复。
所以点「开始」时会调一次 `primeAudio()`；用户点「试听」「换音色」本身也是手势。

万一仍被拦（隐私设置、系统策略），**静默失败**：弹窗照常出现、记录照常写入，只是没声音。
绝不因为「没响」而让人以为这一轮白做了。

### 4.4 音色清单

| 音色 | 听感 | 参数要点 |
| --- | --- | --- |
| 晨钟（默认） | 三音上行，尾巴长，最像下课的钟 | C5→E5→G5，间隔 180 ms，低通 4.2 kHz |
| 木琴 | 短促干爽 | F5/A5/C6，间隔 110 ms，三角波 |
| 八音盒 | 轻、亮、音量最低 | G5/B5/D6，增益 0.08–0.10，低通 6 kHz |
| 风铃 | 错开的高音，像窗外有风 | D6/F♯6/A6/D7，增益 0.03–0.05 |
| 水滴 | 一声下滑，最安静 | 880 → 392 Hz 下滑，低通 2.4 kHz |
| 静音 | 只弹提醒不出声 | — |
| 自定义 | 用户填的音频直链 | 见 4.5 |

### 4.5 「歌单链接」这条要说清楚

用户说「可以选择链接歌单」，但技术上：

- **音频文件直链**（`https://…/x.mp3`）→ ✅ 能播；
- **网易云 / QQ 音乐 / 酷狗 / B 站 / YouTube / Spotify 的歌单、视频页面** → ❌ 播不了。
  那是一个网页，播放器由脚本渲染，`<audio src>` 拿不到音频文件。

所以设置面板只收音频直链，粘平台链接会**当场提示原因**，而不是让它静默失败。
真做「连自己的歌单」需要各平台开放 API + 授权，是另一个量级的工程。

## 5. 双端适配清单

| 项 | 处理 | 为什么必须做 |
| --- | --- | --- |
| iOS 输入框聚焦放大 | `@supports (-webkit-touch-callout: none)` + 手机端 16px | 字号 < 16px 时 Safari 会放大整页，键盘收起后还停在放大状态 |
| 全面屏底部安全区 | 弹窗与页面尾部 `env(safe-area-inset-bottom)` | 否则按钮贴底被 Home 指示条盖住 |
| 触控热区 | 番茄钟的按钮在手机上 44px 高；提示音折叠行 44px | 32px 的按钮在手机上经常点不中 |
| 提示音面板窄屏 | 三列固定、链接输入框独占一行、音量条可换行 | 360px 下自动填充会挤成不等宽的小块 |
| 导航图标 | 手机端 16px、内边距收紧 | 6 个带图标的标签尽量同屏，减少横向滚动 |
| 桌面端 | 图标 17px，不撑高标签（行高 18px > 图标） | 避免加图标后标签栏变高、切换时跳动 |

### 自检覆盖

- **预设完整性**：6 个预设 id 唯一、都有中文名与描述；除静音外都有音符、低通在 2–8 kHz、
  只用 sine/triangle、单音增益 ≤ 0.3、总时长 ≤ 5 秒（提醒音是「一声」，不是一段音乐）。
- **音量夹取**：0.5 原样、1.5 → 1、-1 → 0、NaN → 0.6。
- **链接校验**：空 / 非链接 / ftp / 网易云 / QQ 音乐 / B 站 / 酷狗 / 相似域名不误判 / 自动 trim。
- **偏好清洗**：null、非对象、缺字段、未知音色、custom 空链接回落、音量越界、超长链接截断到 500。
- **渲染**：7 个音色按钮（含自定义）、音量滑块、链接输入框、说明文案、折叠面板容器。

## 附：评审时怎么试

```bash
cd frontend
npm run dev
# 电脑：http://localhost:3000/tools
# 手机：同一 Wi-Fi 下访问终端里打印的 http://192.168.x.x:3000/tools
```

**电脑端**

1. 看标签栏：6 个图标是否都在，切换时背景/文字过渡是否还是原来的顺滑（不该有跳动）；
2. 进番茄钟 → 展开「提示音 · 晨钟」→ 逐个点音色，听是否刺耳、连点是否互相打断而不是叠成噪音；
3. 拖音量到 20%，点「试听」，确认音量真的变小；
4. 粘一个歌单链接（如 `https://music.163.com/#/playlist?id=1`）→ 应提示「这是歌单/视频页面」；
5. 粘一个音频直链 → 点「用这个」→ 试听；
6. 时长设 1 分钟跑一轮 → 到点应同时听到声音 + 看到弹窗。

**手机端（重点）**

1. 打开 `/tools`，标签栏能横向滑动、点击不误触；
2. 在番茄钟里点输入框 —— **页面不应该放大**（这是这次专门修的）；
3. 展开提示音面板，音量条能拖动、链接输入框不挤成一条缝；
4. 跑 1 分钟，看弹窗按钮是否被底部横条挡住、按钮是否好点。
