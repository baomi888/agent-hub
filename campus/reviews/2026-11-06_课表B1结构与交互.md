## 1. 做了什么

课表优化的**第一批，只动结构与交互，不碰数据模型**。四件事：

1. **首访不再塞三门示例课**，换成空状态：一句「还没有课表」+ 两个入口（导入 / 手动添加）+ 一句「JSON 从哪来」。
2. **「添加一门课」从第二张常驻卡片收成头部按钮**，点了在卡片内展开（页内展开 + 0.2s 淡入），再点「收起」回去。
3. **表单重排**：6 个字段带标签，桌面 6 列两行、手机 2 列四行，右边缘对齐。
4. **「本学期设置」弹窗收紧**：开学日期与总周数并排，「或者」分隔线下才是「今天是第几周」。

顺带解决两个一直存在的毛病：

- **点课块只会删课**（`window.confirm`），改个教室要删了重加。现在点课块打开详情，
  详情里能编辑（同一个表单）或删除。
- **学期那行说明占一整行**，且和「学期」按钮离得远。现在收成周次条右端一枚 chip，点开还是学期弹窗。

按 D2 补了一个衔接动作：**导入成功后导入弹窗自动关闭，首次导入紧接着弹学期设置**（可「稍后再说」跳过）。
理由见第 2 节第 3 条。

## 2. 为什么做

| 需求 | 原话 | 这次怎么落 |
| --- | --- | --- |
| 2.1 | 「整体页面太杂乱，要简化」 | 两张卡片合成一张；示例课、常驻表单、独占一行的说明、主按钮「清空课表」全部退场（清空降级为页脚文字按钮） |
| 2.2 | 「添加一门课可以变成一个按键，需要的时候才点开」 | 头部「添加课程」按钮 → 页内展开面板，`aria-expanded` 同步 |
| 3.1 | 「添加一门课的各种排版太不美观，不整齐」 | 换 CSS Grid，字段带标签，两行六格；不再用 `flex: 1.4 1 140px` 硬凑 |
| 5.1 | 「本学期设置那一部分排版太空」（负责人确认：指弹窗） | 420px 宽两列排布 + 分隔线，填满横向空间 |
| A01 | 编辑课程 | 课块 → 详情 → 编辑（复用同一套字段组件） |
| A02 | 空状态 | 删掉示例课之后必须有，否则新用户第一眼是空白格 |

**为什么删示例课**：旧版首访塞「高等数学 / 大学英语 / 数据结构」三门假课，用户点开课表会以为
那是自己的课表，删起来还得一门门确认。空状态把「导入」推到第一屏，路径更短。

**为什么导入后弹学期**：4.4（今天高亮）、4.5（放假变暗）、4.6（休/班）、4.7（节日名）四条
全部依赖「第几周 ↔ 真实日期」，而首访是 `term: null`。不设学期这四条静默失效，
用户会以为没做。导入完那一刻是唯一有耐心填日期的时机，所以放在这里，且允许跳过。

## 5. 风险与未做的事

1. **删示例课只影响新用户**。老用户存档里 `courses` 非空，读的还是自己的课表；
   `sample` 字段保留在类型里（`ScheduleSnapshot.sample`），但新代码不再把它置 `true`，也不再据此做任何判断。
2. **点课块的语义变了**：从「删」变「看」。旧文案「点课块可删除该课程」已随之删除，
   删除现在要「点课块 → 删除这门课 → 二次确认」，多一步但不会再误删。
3. **加课/改课不查同格冲突**（A04 留在后续批次），也不支持「每天几节课可设」（A03，B2）。
4. **节次时间仍写死**（`PERIOD_TIMES`），详情里显示的 `08:00–09:40` 来自这个常量，B2 会变成可编辑。
5. 手机端周次条在 390px 下折成两行（‹ 第 11 周 › 本周 / 视图切换 + 学期 chip），能用但不紧凑，B4 一起收。
