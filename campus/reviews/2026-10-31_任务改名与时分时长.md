## 1. 做了什么

| # | 内容 | 用户看到的变化 |
| --- | --- | --- |
| 1 | 任务改名 | 每个任务多一个「改名」，点开就地变输入框，Enter 保存、Esc 取消 |
| 2 | 时 + 分 双输入 | 时长从「一个月分钟框」变成「__ 小时 __ 分钟」，定 1 小时 30 分不用心算 90 |
| 3 | 快捷芯片 | 25 分 / 45 分 / 1 小时 / 1 小时 30 分，一下点定 |
| 4 | 上限放宽 | 单轮最长从 2 小时提到 12 小时；表盘满 1 小时显示 `1:30:00` |

## 2. 为什么做

原话：「任务可以设置成改名，然后选择倒计时，可以多一个选择，就是 xx 小时 xx 分钟，方便用户快速定时。」

- **改名**：这是之前就发现的缺口 —— 任务只能归档重建，而重建会让历史记录留在旧名字下。
- **时分双输入**：原先只有分钟框，上限 120。想定一次两小时的自习，得先算成 120；
  更长的时段干脆设不了。番茄钟不只是 25 分钟，写论文、做套卷经常是 1–3 小时。
- **快捷芯片**：「快速定时」的落点 —— 多数场景就是那四档，不该每次都敲数字。

## 3. 改动明细

### 新增函数

| 位置 | 函数 | 说明 |
| --- | --- | --- |
| `logic/pomodoro.ts` | `MAX_HOURS` | 由 `MAX_MINUTES` 推导，不另写一个数 |
| | `splitDuration` | 总分钟 → 几小时几分，供两个输入框显示 |
| | `joinDuration` | 几小时几分 → 总分钟，两段各自夹取后整体夹到 `[1, 720]` |
| | `formatDurationLabel` | 「25 分」「1 小时」「1 小时 30 分」 |
| `logic/focusTask.ts` | `renameTask` | 返回 `{ok, tasks, task, changed}` 或 `{ok:false, reason}` |

### 改名规则

1. 去空白后为空 → 拒绝（不把任务变成一行看不见的字）；
2. 与原名相同（忽略大小写与空白）→ `changed: false`，不写一次没必要的存储；
3. 撞上别的任务（含已归档）→ 拒绝。同名并存会让同名去重与按名字归类一起失效；
4. 大类若等于「按旧名字猜出来的结果」→ 跟着新名字重猜；手动设过的保留；
5. **颜色不变** —— 颜色是认任务的第一眼标记，改名后换色反而像换了个任务。

### 时长规则

- 小时框 0–12、分钟框 0–59，两段各自夹取后整体夹到 1–720 分钟。
- 分钟框写 90 **不会**进位成 1 小时 30 分，而是当成 59：输入途中数字自己跳走比"多按一次"更困惑。
- `formatClock` 改为满 1 小时才出小时位：`25:00` / `1:30:00`。以前 100 分钟显示 `100:00`。

## 4. 兼容与风险

| 项 | 结论 |
| --- | --- |
| 存储结构 | **没改**。时长仍只存一个 `minutes` 数字，小时只是显示层的拆分，无迁移 |
| 历史记录 | 改名不回溯旧记录里的 `taskName`（那是当时的快照），这是有意的：改的是"以后叫什么"，不是"过去做过什么" |
| 旧版 120 分钟上限 | 旧数据里最大 120，新逻辑照样接受；只是上限变宽，不会反过来收紧 |
| 表盘显示变化 | 超过 60 分钟的表盘从 `100:00` 变成 `1:40:00`，信息量更大但形态变了，负责人需要认可 |
| 自动大类启发式的边界 | 手动选的大类恰好等于自动识别结果时，改名后会跟着重猜。已写进注释与自检用例 |
| 未跑 `npm run build` | dev server 占着 `.next`，合入前补 |

## 6. 自测建议（负责人）

1. 进番茄钟 → 「我的任务」里点某个任务的「改名」→ 改成别的名字 → 回车，应看到「已改名为「…」」。
2. 再点「改名」→ 清空 → 保存按钮应变灰；输入一个已有的名字 → 保存 → 输入框下出现红字「已经有同名任务了」。
3. 改名时按 Esc → 应原样退出，名字不变。
4. 计时中（点开始后）：所有「改名」「归档」应不可点 —— 防止中途把一段时间记到两个名字下。
5. 时长：小时填 1、分钟填 30 → 表盘应显示 `1:30:00`；点「1 小时 30 分」芯片应得到同样结果且芯片高亮。
6. 分钟框填 90 → 应变成 59（不是 1 小时 30 分）。
7. 时长留 0 时 0 分 → 会变成 0 时 1 分（不允许 0 时长开始）。
8. 手机上：时/分两个框各占一半，「时」「分钟」不换行，4 个芯片能在一行或自然换行。
