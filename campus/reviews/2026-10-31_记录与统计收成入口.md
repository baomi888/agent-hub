## 1. 起因

> 「我希望最近记录的部分，可以变成一个按键，需要看的时候才点击才弹出，节约页面占比。专注统计也一样。」

番茄钟这一页越加越长：0.2.0 只有计时和任务两块，B4 加了统计、B6 加了同步，
到 0.5.3 时桌面端内容 1317px、手机端 1660px。

问题不是「长」，是**长的都是不常用的东西**：

| 区块 | 使用频率 | 占地 |
| --- | --- | --- |
| 专注计时 | 每天几次 | ~410px |
| 我的任务 | 每天一次 | ~300px |
| 最近记录 | 一周看一次 | ~210px |
| 专注统计（含饼图、下钻、导入导出） | 一周看一次 | ~400px |

「选任务 → 开始」这条每天要走的路径被两块「偶尔查一下」的内容夹在中间，得滚两屏。

## 2. 改成什么

### 2.1 两块内容 → 两个入口按钮

主屏现在是三块：**专注计时 / 我的任务 / 一排两个入口**。

```
[ 最近记录            12 条 › ]  [ 专注统计      今日 1.5 小时 › ]
```

按钮右侧给一个**当下的数字**（共几条 / 今日累计），不打开也知道值不值得点。
数字为 0 时不说「不到 1 分钟」——`humanizeSeconds(0)` 会这么讲，放在按钮上像出错了，
所以显式改成「还没有」「今日还没有」。

### 2.2 浮层复用完成弹窗那一套

新增 `PanelSheet.tsx`：

| 行为 | 做法 |
| --- | --- |
| 语义 | `role="dialog"` + `aria-modal="true"` + `aria-labelledby` 指向标题 |
| 关闭 | Esc / 点遮罩 / 点右上角 ×，三条路都通 |
| 焦点 | 打开时移到面板容器（`tabIndex={-1}`），读屏先念标题；不落在 × 上 |
| 长内容 | 标题行固定，`.campus-sheet-body` 自己滚（`overscroll-behavior: contain`） |
| 背景 | 遮罩沿用 `.campus-modal-mask`，与完成弹窗同一个视觉 |

`StatsPanel` 不再画卡片外壳、不写标题 —— 它只负责内容，标题与关闭由 `PanelSheet` 给。
`最近记录` 的列表搬进 `RecentLog.tsx`，显示条数从 5 条放宽到 50 条（浮层比卡片高得多）。

### 2.3 顺带修掉一个一直没生效的东西

完成弹窗原本用 `document.body.style.overflow = "hidden"` 锁滚动。**这条在 0.5.3 之后彻底失效了**：
页面滚动发生在外层 `.campus-scroll` 上，而 `html/body` 本来就是 `overflow: hidden`，
改 body 拦不住 `.campus-scroll`。

新增 `logic/scrollLock.ts`（带计数，支持嵌套），给 `body` 打 `campus-sheet-open` 类，CSS 收口：

```css
body.campus-sheet-open .campus-scroll { overflow: hidden; }
```

完成弹窗与两个浮层共用这一套，关掉时按计数归还。

## 3. 一处翻车与修法（留档）

第一版给统计内容包了一层 `<div className="campus-stats">`。**`campus-stats` 这个名字在 GPA 工具里
已经是「3 列网格」的统计卡**，同名直接把浮层内容排成三列 —— 日期、四个数字、空状态并排挤在
436px 高的面板里，数字被压成竖排单字。

改名为 `.campus-pomo-stats`（纯块级），并在 CSS 里写了注释说明为什么不能叫这个名字。
教训：**板块内所有类名都要带工具前缀**，`campus-` 开头的通用名早就被别的工具占了。

修复后实测：桌面 `.campus-stats-nums` 宽 586px、4 列各 139px；手机 2 列各 159px。

## 5. 没做的

- **没做过渡动画**。浮层是直接出现/消失的，与完成弹窗一致；要淡入得先确认在
  `prefers-reduced-motion` 下的降级，单独一轮做。
- **没做焦点循环（focus trap）**。目前只做「打开时移入 + Esc 关闭」，Tab 到底会跑到遮罩后面的页面上。
  完成弹窗也是这个水平，要补应该两个一起补。
- **没动 `campus-shell` 的 880px 单栏**。桌面端内容居中是因为这是工具页不是看板，
  上一轮已确认过这个决定，这次没有重开。
