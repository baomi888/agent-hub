## 1. 系统全景（分层）

```
┌─────────────────────────────────────────────────────────────┐
│  浏览器                                                       │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP  :3000
┌───────────────────────────▼─────────────────────────────────┐
│  展示层  frontend/           Next.js 16.3.5 + React 19       │
│    src/app/        页面路由（page.tsx / templates）           │
│    src/components/ UI 组件（Sidebar / ChatArea / KBPanel…）   │
│    src/lib/        接口封装（api.ts / sse.ts / hooks）         │
│    ★ 前端不直连后端端口，靠 next.config.ts 的 rewrite 代理     │
└───────────────────────────┬─────────────────────────────────┘
                            │ /api/*  →  http://localhost:8000/api/*
┌───────────────────────────▼─────────────────────────────────┐
│  接口层  api/ + main.py      FastAPI（路由 / 鉴权 / 参数校验） │
│    auth chat kb sessions feedback geo templates usage        │
│    ★ 默认全鉴权：业务 router 挂 Depends(get_current_user)      │
└───────────────────────────┬─────────────────────────────────┘
                            │ 调用纯业务函数
┌───────────────────────────▼─────────────────────────────────┐
│  业务核心层  core/ + agent/ + kb/                             │
│    core/    账号 / 会话 / 配额 / 配置 / LLM / 网络安全          │
│    agent/   LangChain Agent 编排 + 工具集                     │
│    kb/      知识库流水线 + 向量检索 + 网页导入                  │
└───────────────────────────┬─────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────┐
│  数据层                                                       │
│    SQLite   data/sessions.db   会话 / 消息 / 用户              │
│    SQLite   data/scheduler.db  调度三张表（队友新增）           │
│    Chroma   chroma_db/         向量库（按 kb_id 分 collection） │
│    ️文件    data/kb_sources/ 等 上传原文 / 索引元数据           │
└─────────────────────────────────────────────────────────────┘

        外部依赖：DeepSeek Chat（对话）
                  阿里百炼 DashScope（embedding + 视觉）
                  Serper（联网搜索）/ 高德（天气）
```

**关键约定**

- **后端只监听 `127.0.0.1:8000`**，不对外。前端经 `/api/*` rewrite 访问，公网只暴露 `:3000`。
  这样少一层暴露面，也避免 `:8000` 直连绕过 Next 的 Cookie 域设置导致登录态丢失。
- **`redirect_slashes=False`** + `normalize_api_slash` 中间件：尾斜杠由本项目自己归一，
  不能让 FastAPI 自动 307（那条 Location 指向 `localhost:8000`，浏览器必然失败）。
- **新增端点默认要登录**：业务 router 统一挂 `dependencies=[Depends(get_current_user)]`，
  忘了写鉴权时默认落在安全的一侧。

| `src/lib/hooks/*` | 状态 hooks（`useAuth` / `useSessions` / `useKnowledge` / `usePrefs` / `useToast`） |

**前端硬规则**

1. 后端调用**只允许**出现在 `src/lib/api.ts`。组件里直接写 `fetch("/api/...")` 一律打回。
2. 颜色 / 间距 / 字号**只能**用 `styles/tokens.css` 的变量，禁止硬编码色值。
3. 新增页面必须纳入 `AuthGate`（当前 `/templates` 是已知缺口）。
4. 全站**不使用 emoji 或字符图标**，统一用 `components/CornIcon.tsx` 图标集（30 枚）。

## 6. 跨模块改动流程

改动**别人归属**的文件时，按下面走，不允许静默改：

1. **先通知**：在群/issue 里说清楚「改哪个文件、为什么、影响面」。
2. **建独立分支**：`feat/跨模块-简述-日期`，不要混进自己的功能分支。
3. **小步提交**：一个提交只做一件事，便于对方 review 和回滚。
4. **拉对方做 reviewer**（见 `03_流程规范.md` §4），CODEOWNERS 会自动点名。
5. **合并后同步文档**：若改变了职责边界或契约，更新本文件与 `02`。

**必须跨模块协商的典型场景**

- 新增横切能力（认证 / 配额 / 限流）：涉及 `core/quota.py` + `main.py` + 前端错误文案 + 测试，四处都要动。
- 改变响应形状：涉及 `api/schemas.py` + 前端 `lib/types.ts` + 前端解析逻辑。
- 新增数据库表：涉及 `core/session.py` 或 `core/scheduler.py` + 数据结构文档 + 备份策略。
