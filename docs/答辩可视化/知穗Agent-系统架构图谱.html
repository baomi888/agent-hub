MODULE 04 · KNOWLEDGE & RETRIEVAL

知识与检索：四段流水线 + 双通道召回 + 依据判定

入库按库加锁、向量库每库一个 collection；检索先扩召回再去重，最后用相似度阈值决定「说不准」· 点击图表可放大

覆盖模块入库链路、Chroma 按库隔离、混合检索、缓存与指纹守卫、依据判定、联网导入
关键结论扩召回 → 阈值 → RRF 融合 → MMR 四段解决「引用重复、专有名词漏召回」；0.45 以下主动承认依据不足。
可能被追问为什么没有 rerank：每次检索多一次模型往返，当前 2C2G 预算下性价比不高。

单机 2C2G 的务实方案：后端只监听回环，前端同源代理；发布脚本一条命令，失败可回滚到上一版· 点击图表可放大

扩召回 → 阈值 → 融合 → MMR → top-k；相似度低于 0.45 时主动承认「依据不足」· 点击图表可放大
