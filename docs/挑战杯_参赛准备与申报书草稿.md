### B3. 申报作品情况（科技发明制作）

**作品分类**（打钩）：**（ ✓ ）B．信息技术（包括计算机、电信、通讯、电子等）**

**作品设计、发明的目的和基本思路，创新点，技术关键和主要技术指标**
> 目的：当前大学生在课程学习、考研、论文写作中面临"资料零散、问答无可靠出处、工具分散"的痛点。本项目面向高校学生，构建一套可私有部署的一站式智能体平台，将 RAG 知识库、多轮对话 Agent 与校园实用工具整合，强调"辅助学习而非替代思考"的 AI 素养导向。
> 基本思路：先通过问卷调研大学生真实需求（已回收有效问卷，见佐证），再设计"前端体验—后端服务—向量检索—智能体编排"四层架构；以 FastAPI 提供全链路 SSE 流式服务，Next.js 实现苞米地笔记本风格界面；通过多用户强隔离保证数据安全。
> 创新点：① **模板广场**——以"教搭建而非代做"的 8 类校园场景模板降低上手门槛，强化 AI 素养；② **强数据隔离的多用户架构**——按 owner 强制隔离，归属校验失败返回 404 而非 403，避免越权；③ **RAG 三段式重排检索**——候选池扩召回→余弦离群过滤→MMR 多样性去重，显著提升引用质量；④ **苞米地独特 UI 设计语言**——手绘吉祥物 + 暖米黄纸风格，区别于通用 SaaS 后台；⑤ **零门槛校园工具集**——纯前端 GPA/课程表/抽签等工具，无需登录即可用。
> 技术关键：异步 FastAPI + 手写 StreamingResponse 实现流式；LangChain v1 编排 Agent 五工具（知识库检索/联网搜索/计算/天气/下载）；Chroma 进程级单例保证多库隔离；SQLite WAL 参数化存储。
> 主要技术指标：检索 top_k=3、MMR λ=0.65、相似度下限 0.25；实测只读接口 8 并发 P50≈34ms，SSE 问答 3 并发端到端≈1.64s，文档上传 3 并发≈2.78s。

**作品的科学性、先进性**（必须说明与现有技术相比的突出实质性特点和显著进步，附参考文献）
> 与通用对话工具（ChatGPT、国内大模型网页版）相比：① 所有回答带可点击的原文角标，解决"AI 胡编"痛点，体现学术严谨；② 私有知识库隔离，资料不出校、不出个人；③ 多用户数据强隔离，适配校园多账号共用场景。与通用 RAG 框架相比：三段式重排（扩召回+离群过滤+MMR）在 top-k 名额有限时有效避免相邻重复切片占满，提升引用多样性与相关性。平台遵循主流工程规范（分层架构、集中配置校验、结构化日志、JWT 短时效令牌 + 服务端刷新令牌、配额与限流）。
> 参考文献（建议补充 3–5 篇，如 RAG 检索增强生成综述、MMR 多样性排序原文、LangChain Agent 文档等）。
