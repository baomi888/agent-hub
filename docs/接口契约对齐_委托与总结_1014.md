## 一、🔴 字段名不一致（3 处，后端一上线委托页直接报错）

后端 `_out()`（`api/delegate.py:125`）返回的字段名，与我前端 `types.ts::Delegate` 差 3 个。
**后端定义的字段名 = 契约，建议后端改**（改 3 行，比前端全站改字段引用便宜，且不破坏已有 curl 调试习惯）。

| # | 后端 `_out()` 返回 | 我前端 `Delegate` 期望 | 影响 |
|---|---|---|---|
| 1 | `delegation_id` | `id` | 列表能渲染，但**所有按 id 的操作（编辑/暂停/删除/预览/执行）全部拿不到 id ⇒ 按钮必点不动** |
| 2 | `prompt` | `instruction` | 表单回显为空，用户以为没保存 |
| 3 | `deliver_sid` | `session_id` | 投递目标会话显示为空 |

附带 2 处**信息缺失**（非报错，但页面上会少东西）：

| 后端有 | 我前端期望 | 说明 |
|---|---|---|
| `updated_at` | — | 多一个字段，前端可忽略 |
| — | `session_title` / `kb_name` | **后端没返回**，我前端类型里声明了。页面若用到会渲染空白，需后端补 join 或前端删掉声明 |

**最小改动方案（后端侧，改 `_out()` 一处即可）**：

```python
return {
    "id": d["delegation_id"],          # 兼容前端；同时保留 delegation_id 供调试
    "delegation_id": d["delegation_id"],
    "name": d["name"],
    "kind": d["kind"],
    "schedule": sched,
    "prompt": d.get("prompt") or "",
    "instruction": d.get("prompt") or "",   # 同上，双写
    "session_id": d.get("deliver_sid"),
    "deliver_sid": d.get("deliver_sid"),
    "kb_id": d.get("kb_id"),
    "session_title": ...,                  # 若要前端显示，需 join conversations.title
    "kb_name": ...,                        # 若要前端显示，需 join kb_names
    "tone": d.get("tone") or "neutral",
    "max_chars": d.get("max_chars"),
    "enabled": bool(d.get("enabled")),
    "next_run_at": d.get("next_run_at"),
    "created_at": d.get("created_at"),
    "updated_at": d.get("updated_at"),
}
```

> 双写（两个 key 都给）是最省事的过渡期写法：不影响你们后端内部 `delegations.delegation_id` 的用法，
> 前端也不用动类型。契约稳定后前端再收敛到单字段。

## 三、🟡 尾斜杠：与线上既有修复有冲突，需统一（这条最急）

**后端所有 delegate 路由都带尾斜杠**：`GET /`、`POST /`、`/{id}/`、`/{id}/run`、`/{id}/runs`。
我前端 `api.ts` 请求的路径**绝大多数不带**尾斜杠（`/api/delegate/${id}`）。

而本项目**线上已经因为尾斜杠出过一次事故**（10-02，`docs/知穗_UI设计规范` 有记录）：
FastAPI 补 307 → Next 去尾斜杠 308 → Location 指向用户自己机器 ⇒ 登录态丢失、页面白屏。
当时的修法是 `redirect_slashes=False` + 中间件 `normalize_api_slash` 双向归一。

**这意味着现在两种写法都能命中，但取决于那个中间件是否覆盖了所有新路径**。我不想赌，所以请后端明确二选一：

| 方案 | 说明 | 成本 |
|---|---|---|
| **A（推荐）** | 后端**去掉**所有路由尾斜杠，与项目其余 35 个端点一致 | 后端 5 处删 `/` |
| B | 保留尾斜杠，但确认 `normalize_api_slash` 中间件已覆盖 `/api/delegate/*` | 需在中间件加一条前缀 |

我倾向 **A**：项目里其余 35 个端点都不带尾斜杠，delegate 是唯一的例外；
而且 10/02 那次事故的根因就是「两边都在改斜杠」。
