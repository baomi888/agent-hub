## 二、访问权限与可见性：查了，不需要动

用户要求「检查是否需要同步调整」。逐条查过，结论是**这一批只改名字，权限一行没动**，
理由如下：

| 检查项 | 现状 | 结论 |
|---|---|---|
| `GET /api/kb/public` | `Depends(get_current_user)`，登录才给列表 | 广场对**登录用户**开放，匿名 401；与改名无关，未动 |
| `GET /public/{kb_id}`、`/file`、`/text` | 同样要求登录 | 同上 |
| 留言板 `GET/POST /public/{kb_id}/board` | 同样要求登录 | 与论坛（已免登录）**不一致**，但这是产品决定，不属本批 |
| 广场只列 `public=1` 且未删除的库 | `pipelines.list_public` | 私有库不会漏出来 |
| 自己的库是否出现在广场 | 后端按 `owned_kb_ids` 排除，前端另有「我的」分组 | 一致 |
| 广场卡片是否漏 uid | 只回 `owner_name` 显示名 | 未变 |
| 分享后的可见性说明 | 分享弹层写「公开后全站登录用户都能在对话里检索它」 | 与新名称不冲突，未改 |

一句话：**改名不影响权限**；「公开知识库」这个名字里虽然带"公开"，但它一直就是
"登录用户可见"，不是"互联网公开"。

## 三、深色吉祥物：为什么会"恐怖"

把用户截图放大 4 倍看，能拆出三层成因，缺一层都不会有那种观感：

1. **五官走 `currentColor`**。浅色下 `--ink` 是 `#3D2F1A`（墨棕），深色下变成
   `#EDE0C4`（浅米白）—— 于是眼睛成了**两颗白亮点**、描边成了发光边、嘴成了发光的弧。
2. **脸是固定的 `#F5B840`**，在 `#1A1610` 的纸面上像自发光体。
3. **`components.css` 给 `.corn-logo` 挂了 8px / 0.3 的金色光晕**，把"内部发亮"钉死。

三者叠加 = 一颗亮着黄光的虫蛹，上面两个白洞。用户说"恐怖"是完全准确的。

### 改法：给吉祥物一套自己的深色变量

`.mascot` 上定义一组 `--mc-*`（浅色值与原硬编码**逐值相同**，视觉零变化），
`.dark .mascot` 覆盖成深色那套：

| 变量 | 浅色 | 深色 | 为什么 |
|---|---|---|---|
| `--mc-face` | `#f5b840` | `#e3ab52` | 降到哑光焦糖，对纸底 8.76:1，看得清但不发光 |
| `--mc-eye` / `--mc-mouth` | `currentColor` | `#2b1d0e` | **最关键一条**：五官压暗，眼对脸 7.95:1 |
| `--mc-stroke` | `currentColor` | `#6e4f28` | 暖棕描边，对脸 3.63:1、对纸底 2.6:1，不靠光晕也立得住 |
| `--mc-silk` | `currentColor` | `#a9834c` | 顶端三缕须比描边亮一档，否则在暗纸面上糊成"三根触角" |
| `--mc-leaf-a/b` | `#7c9a54` / `#8faf62` | `#55703b` / `#66854a` | 橄榄绿降饱和，暗底上不刺眼 |
| `--mc-grain` | `currentColor` @0.28 | `#4a3318` @0.2 | 浅墨纹在暗底会变成"壳上的裂纹" |
| `--mc-shine` | `#ffffff` @0.5 | **`display:none`** | 它是"纸上有光"的暗示，深色里没有对应物，0.22 只剩一块灰脏斑 |
| `--mc-blush` | `#ef8a56` | `#c9714a` @0.72 | 焦糖脸上腮红要更实，这两坨暖色是"亲切"的主要来源 |

光晕同时从 `8px / 0.3` 压到 `4px / 0.14`。

### 表情与细节（浅色也一起吃）

- 眼睛半径 4.6 → 5.0，高光 1.7 → 1.9，并在左下加一颗 0.9 的小点 —— 双高光让眼神"有神"，
  单高光在大尺寸下容易看成玻璃球。
- 嘴的弧线略放宽（`Q60 73.6`）、描边 4 → 3.9，笑起来更松。
- 顶端三缕须独立成 `--mc-silk` 变量。

### 顺带修掉的一个隐患

`landing.css` 里原来用 `path[stroke="#FFFFFF"]` 隐藏落地页大号头上的那道高光。
颜色改成变量后这个选择器**永远选不中**，190px 那只头上会重新出现"灰胶布"。
改成按类名选（`.lp-mascot-fig .mascot-shine`），以后颜色怎么改都不影响这条规则。
