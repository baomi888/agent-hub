# 视觉基线 v13：工具型 AI 整理

> 日期：2026-11-10
> 当前原型：`prototype.html`（v13）
> 验收：`去AI味与引导性验收.md`
> 历史基线：`视觉基线_v12.md` 只用于回看演进，不得作为实现依据

## 1. 这一版解决什么

v12 解决了“输入固定在底部”，但把整理过程做成了聊天：
AI 头像、问候气泡、第一人称旁白、深墨用户气泡。功能能用，但 AI 味重，
用户不知道下一步该做什么。

v13 改成工具：

> AI 是后台能力，界面只负责让用户看清“说什么、整理出了什么、点下去会发生什么”。

保留：

- 底部一句话输入；
- 自然语言拆成待办和提醒；
- 原话可回看；
- 用户确认后才写库。

去掉：

- AI 头像、问候气泡、深墨聊天气泡；
- “我听到 / 我拿不准 / 我在整理 / 我先把听到的排好了”；
- 满屏 spark、假进度、假记忆、过度承诺。

## 2. 三层结构

| 层 | 内容 | 约束 |
|---|---|---|
| 顶部 | 步骤条 `1 说一句 → 2 确认 → 3 加入`、标题、副标题、关闭 | 固定，不随内容滚动 |
| 整理区 | 输入态说明 / “你说的”引用卡 / `正在整理…` / 结果列表 | 独立滚动，底部留出 composer |
| 底部 | 示例句、信任说明、麦克风、输入框、发送 | 输入态固定在抽屉底部 |

标题：

- 输入态：`整理成待办和提醒`
- 输入态副标题：`自动拆成待办和提醒；确认后才会加入。`
- 结果态：`确认这 N 条`
- 结果态副标题：`确认后才会加入；N 条需要补充信息。`

## 3. 输入态

顺序必须是：

1. 说明：`说清「什么时候、要做什么」`
2. 具体示例：`例：明天交高数作业，周五社团开会，每晚背单词`
3. 当前上下文：`今天已有 4 件安排 · 下一件 20:00 背单词`
4. 空态：`说完，整理好的安排会出现在这里`
5. 示例句：只填入，不提交
6. composer：麦克风 + 输入框 + 发送
7. 信任说明：`说错也没关系，整理完可以逐条改。`

规则：

- 输入为空：发送 disabled，不能拿示例句偷偷提交；
- 输入非空：发送可用；
- Enter 发送；中文输入法 `isComposing` 时不发送；
- 发送后说明区隐藏，只保留引用卡、`正在整理…`、composer；
- 发送后 composer 锁定，防重复提交。

## 4. 整理中

只出现两块：

```text
你说的
明天高数作业要交，周六社团开会，今晚背单词，下周课程论文

文字 · 刚刚

正在整理…
```

不要出现：

- AI 头像；
- “我在整理成待办…”；
- 假的三段式进度；
- 逐字打字机。

## 5. 结果态

自上而下：

1. 汇总条：`4 条 · 2 条待办 · 2 个日程`
2. 需要确认时：`先处理 2 条需确认 ↓`
3. “你说的”引用卡，原话高亮 + 编号
4. 逐条检查
5. 每条状态：`可直接加入 / 需要确认 / 缺少时间`
6. 待办 `○`，日程/提醒 `◇`
7. 底栏：`已选 N 条 · M 条会提醒` + `全不选` + 主按钮

主按钮写后果，不写空话：

- `加入 4 条，并设 3 条提醒`
- `加入 3 条，并设 3 条提醒`
- `加入 4 条，不设提醒`
- 全不选：`先选一条`，disabled

成功 toast 必须与选择一致：

```text
已加入 3 条，其中 3 条会提醒你
今天 1 条 / 明天 1 条 / 周六 1 条
```

## 6. 文案边界

可以说：

- `正在整理…`
- `需要确认`
- `缺少时间`
- `只设截止时间，不会收到提醒。想被提醒，请单独设置。`
- `说错也没关系，整理完可以逐条改。`
- `加入 4 条，并设 3 条提醒`

不要说：

- `我听到`
- `我拿不准`
- `我建议`
- `我懂你`
- `放心交给我`
- `太棒了，已经帮你搞定`
- `智能识别 / AI 正在思考 / 已为你分析`

## 7. 与 v12 的差异

| v12 | v13 |
|---|---|
| AI 头像 + 问候气泡 | 无头像，直接说明 |
| 深墨用户气泡 | “你说的”引用卡 |
| “我在整理成待办…” | `正在整理…` |
| “我先把听到的排好了” | `确认这 4 条` |
| 标题“说给我听” | `整理成待办和提醒` |
| 没有步骤条 | `1 说一句 → 2 确认 → 3 加入` |
| 结果只有列表 | 汇总条 + 需确认路由 + 状态 pill |
| 空输入可用示例句提交 | 空输入 disabled |
