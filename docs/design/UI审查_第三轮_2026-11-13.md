> 2026-11-13 · 冯靖豪 · 承接 `2d74ba6`（第三批）、`3ba844c`（工具集返回入口收起）
> 本轮起点就是上一轮留下的那条缺口：「桌面端工具集仍然没有侧栏」。

## 〇、用户原话与拆解

> 「就是我不想点开工具集这个模块还要跳到一个独立的页面，想要和跳转设置这些一样」

一句话里有三个要求，缺一个都算没做到：

1. **不要"跳走"** —— 点进来不能是「整屏换掉」，侧栏 / 底部 tab 必须还在；
2. **和设置一样** —— 页头也应该是控制台的页头（眉题 + 标题 + 说明），不是自己写的一套；
3. **能直接切走** —— 不用先点「← 回首页」。

上一轮的处理是「保留独立页 + 单独挂一条 tab」，只满足了第 3 条。这一轮把前两条补上：
**路由搬进 `(console)`，外壳由 layout 统一挂**。

## 一、根因：是不是"独立页"由路由组决定，不由页面决定

```
frontend/src/app/
├── (console)/            ← layout.tsx 里挂 ConsoleLayout：侧栏 + tab + 滚动容器 + 登录门
│   ├── settings/         ← 用户心里的"正常页面"
│   ├── reminders/
│   └── tools/            ← 本轮搬进来
└── (campus)/             ← 只有一个 template.tsx（淡入），没有任何外壳   ← 已删除
    └── tools/            ← 原来在这儿
```

`(campus)` 这个组没有 layout，所以 `/tools` 的 DOM 从 `<body>` 直接就是页面内容 ——
这正是"整屏换掉"的来源。搬一个目录就能解决，但**页面自己得先把三层东西交出去**：

| 页面自带的东西 | 交还给谁 |
|---|---|
| `.campus-scroll`（`height:100dvh` + `overflow-y:auto`） | `.console-scroll` |
| `.campus-head`（`h1` + 说明段） | `PageShell` 的 `.pg-head` |
| `.campus-bar`（← 回首页 + 知穗 AGENT） | 侧栏 / 底部 tab，**整块删除** |
| `CampusTabBar`（单独挂的那条 tab） | `ConsoleLayout` 里那一条，**整块删除** |

## 四、顺带发现并修掉的两件事

### 4.1 弹窗锁滚动会静默失效

`campus/logic/scrollLock.ts` 只做一件事：给 `<body>` 打 `campus-modal-open`。
锁哪一层由 CSS 决定，原来是：

```css
body.campus-modal-open .campus-scroll { overflow: hidden }
```

`.campus-scroll` 搬走之后这条选择器**命中不到任何元素**。表现是：番茄钟「本轮完成」
弹窗和单词卡全屏打开时，背后的页面照样滚 —— 没有报错、没有红，只有手感不对。

改成 `.console-scroll`，并加断言钉住（少了这条，下次再换外壳还会静默失效）。

### 4.2 整个文档被撑高 26px，`window.scrollTo` 真能滚

并进外壳后第一次量：`/tools` 的 `document.scrollHeight` 是 **870**，`window.scrollTo(0,400)`
居然真的滚到了 26；同一外壳下的 `/reminders` 和 `/settings` 都是 844 / 滚不动。

所以不是外壳的锅。逐个排查后只剩一个溢出元素：

```html
<th><span class="sr-only">操作</span></th>   <!-- Tailwind 的 sr-only：position:absolute，1px -->
```

表格没有定位祖先，它相对**初始包含块**定位，静态位置落在第 869px，把 `html` 的
`scrollHeight` 顶到 870。`html` 是 `overflow:hidden`，用户滚轮滚不动，但**程序能滚**：
焦点跳到视口外的输入框时浏览器会把整页推上去，`fixed` 的底部 tab 与背景瞬间错位一下。

修法两选一，最后选了后者：

| 方案 | 效果 | 风险 |
|---|---|---|
| `.campus-shell { position: relative }` | 870 → 844 ✓ | shell 里还有一堆 `absolute` 元素（工具溢出菜单、饼图中心字、课表块），换基准会把它们一起搬 |
| `.campus-table { position: relative }` | 870 → 844 ✓ | 只影响表格，表格位置实测未变（`top:840` 前后一致） |

## 五、代价（必须说清楚）

**`/tools` 从此需要登录。**

`ConsoleLayout` 里有登录门（未登录渲染 `AuthGate`），而这一页原来在 `(campus)` 组里是
免登录可访问的。真实入口本来都在登录后（侧栏、「更多」面板、首页工具行），所以
**不影响任何正常路径**，但两类人会遇到变化：

- 手输 / 收藏过 `https://myzhisui.cn/tools` 的未登录访客 → 现在会看到登录页；
- 页面里那句「不用登录、不连教务，打开就能用」→ 已改成「数据先存在这台设备上，
  登录后会同步到云端」，GPA 面板底下那句「不上传、不需要登录」也一并改了。

如果以后确实需要"未登录也能用工具集"，做法是给 ConsoleLayout 加一个公开路由白名单，
而不是把页面再搬回独立组 —— 那时 `GuideModal` / `AnnounceModal` 要处理 `me == null`。

## 六、没验到的

1. **仍未上真机**。全程 Edge 157 headless 模拟 390×844，`env(safe-area-inset-bottom)`
   在模拟器里恒为 0。iPhone 的 home 条、安卓 Chrome 的地址栏伸缩，都没有真实数据。
2. **平板 900–1024 区间**依旧没单独截图。这一轮改动不涉及断点（tab ≤900 出现是上一轮的事），
   但那个区间"两边都没有导航"的老问题**仍然存在**：侧栏 ≤900 隐藏，tab 也只 ≤900 出现。
3. **880 版心在宽内容区里留白 132px**（1440 下）。这是独立页时期就有的设计，
   本轮没动 —— 想让工具集铺满的话，改 `--campus-max` 一处即可，但六面板的栅格要在
   1144 宽度下重新看一遍，本轮没做。
4. **未登录直连 /tools 的体验**没截图（只确认了会落到 AuthGate）。
