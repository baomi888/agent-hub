# 论坛左上角「回工作台」_2026-11-15

用户截图问：「论坛左上角的小图标旁增加明确的文字提示或悬停说明，告知用户该图标
用于返回主页」。

---

## 一、为什么用户看不懂

三件事叠在一起，缺一件都还看得懂：

| # | 现象 | 后果 |
|---|---|---|
| 1 | 手机端 `.tb-logo-t`（站名「知穗论坛」）被 `display: none` | 这一行只剩一个 28px 的方块 |
| 2 | 方块里画的是 `CornIcon name="task"`（勾选框 + 两条线） | 图标本身不表达"返回"，也不指向"主页" |
| 3 | 只有 `aria-label`，没有 `title` | 鼠标悬停没有任何提示；`aria-label` 只对读屏器说话 |

桌面端有「知穗论坛」四个字兜底（站名即入口是 Web 通用惯例），所以问题只在手机端
暴露 —— 而用户恰好截的是手机端。

---

## 二、解法

**桌面端**：保留 `[task 方块] 知穗论坛`，补 `title="返回工作台"`（站内其它图标按钮
同样用原生 `title`，`Bubble.tsx` 里有十几处先例）。

**手机端**（≤760）：

```
[金底方块 + ← ]  工作台        [ 搜索栏 ]   [ + 发帖 ]
```

- 方块里的 `task` 换成左箭头 → 图标终于表达"返回"；
- 方块右边补「工作台」三个字 —— 比原来藏起来的四字标题**更窄**，
  却把动作说清楚了；
- 站名改用 sr-only 而不是 `display:none`：它是整页唯一的 `<h1>`，
  原来那样藏，读屏用户会拿到一个没有标题的页面（视觉上看不出区别，
  所以这个坑一直隐形）。

---

## 三、两个踩到的坑

**① `CornIcon` 的 `back` 图标不能直接用在这一处。**
它的 V 形写死了品牌金 `#F5B840`，而方块底色是 `--accent`（同样偏金）。
两金相叠 **1.5:1** —— 第一版上线后截图里只剩一条深色横线，看着像减号。
`CornIcon` 里那个 `back` 是为「米色底 + 深棕描边」场景画的（详情页「返回列表」），
不能为了这一处改掉它。改成在 `page.tsx` 里内联一个同形状的 `BackMark`，
整条描边走 `currentColor`。修完实测：浅色 **5.33:1**、深色 **7.43:1**。

**② 方块里的图标颜色不能再跟 `--ink` 走。**
深色主题下 `--ink` 是浅米（`#EDE0C4`），压在亮金 `#E0A03A` 上只有 **2:1**。
改用 `--on-accent`（浅色 `#2A2113` / 深色 `#231C11`）—— 令牌注释里本来就写着
"两套主题里 #231C11 都能用"，这才是它的用途。

**③ 注释里的代码会骗过正则。**
新断言的初版写的是 `re.search(r'<CornIcon name="back"[^>]*/>', page)`，
而组件的注释里恰好也写着 `<CornIcon name="back" />` 这个标签 —— 组件已经换掉了，
断言照样绿。改成认 `<BackMark />`，并把注释里的尖括号写法去掉。

## 五、没验 / 已知缺口

1. **320 宽下搜索框的占位文字被截**（输入区 60px，六字占位要 96px）。
   没为它加规则：这个宽度下「返回 + 搜索 + 发帖」三件套怎么排都挤，
   硬缩字号只是把问题挪个位置。360 起完整显示。
2. 全部读数来自 headless Chromium，**没上真机**；没验横屏。
3. 详情页左上角那个方块指向 `/forum`，右侧已有「← 返回列表」四个字，
   所以只补了 `title="返回论坛列表"`，没再给它配可见文字。
4. 论坛页仍然没有底部导航栏（审查报告 P0-2），与本批无关。
