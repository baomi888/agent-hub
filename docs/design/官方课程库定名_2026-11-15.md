# 「官方课程库」定名：把真名收成一处

- 日期：2026-11-15（第 19 批）
- 起因：用户对上一轮列出的两个开放问题回了一个「改」
- 代码：本批提交见文末

---

## 一、要解决的不是"哪个词好听"，是"真名存了几份"

这一区原本有四个地方各自写着同一个名字，写法还都不一样：

| 位置 | 改前 | 改后 |
|---|---|---|
| 广场分区眉题 `library/page.tsx` | 官方公开知识库 | **官方课程库** |
| 收藏行的来源标签（后端拼串）`api/kb.py` | 来源**官方资料库** | 来源**官方课程库** |
| 库详情页副标题 `library/[kbId]/page.tsx` | 官方公开知识库 · 在线预览或下载 | **官方课程库** · 在线预览或下载 |
| 注释 / 类型文档（`types.ts`、`KnowledgePanel`、`knowledge/page.tsx`、`library.css`） | 「官方知识库」×2、「官方资料库」×1 | 统一说「官方课程库」 |

同一屏上会同时出现两个词：上面眉题写「官方公开知识库」，下面收藏行的标签写
「来源官方资料库」—— 用户看到的是"这两个是不是两个东西"。

**改前的守卫为什么没拦住**：`tests/test_naming_consistency.py` 当时写的是

```python
assert '"source": "官方资料库"' in kb   # ← 把旧名字写死进了测试
```

于是眉题改掉之后测试照样绿 —— 等于**真名多存了一份，而且存在测试里**。

## 二、改法：真名只留一处

现在唯一的真名是广场那一区的眉题，其余三处都**往上对**：

```python
_OFFICIAL_SECTION = re.compile(
    r'<section className="lib-sec lib-official">.*?<span className="eyebrow">([^<]+)</span>', re.S
)
```

断言做成两条关系：

1. 后端 `"source": "X" if official` 的 `X` **逐字等于**眉题；
2. 详情页副标题必须是 `"X · 在线预览或下载"`。

再补一条负面：`X` 里不许出现「知识库」（全站只留「公开知识库」这一个整词，
见 `test_ui_never_says_zhishiku`），以及 `官方知识库` / `官方资料库` 两个历史词
不许以**展示串**身份回来。

★ 正则锚在 `section` 上，不是全页找第一个 `.eyebrow`：这一页有四个区
（官方 / 我分享的 / 我的收藏库 / 同学分享的），按"第一个"找会随排版顺序静默指错区。

## 三、为什么是「官方课程库」而不是「公开知识库」

- 广场 h1 已经是**「公开知识库」**，那是整页的名字；这一区是它的子集，
  再叫一遍「公开知识库」等于用页名当分区名。
- 同页另外三个眉题是「我分享的 / 我的收藏库 / 同学分享的」——都短。只有它
  原来是五个字的叠词（官方＋公开＋知识库）。
- 这一区自己的文案早就在说「课」：h2 是「官方课程**资料**，和同学分享的资料库」，
  计数是「**N 门课程**」，`types.ts` / `api.ts` / `KbBoard.tsx` 的注释一律叫
  「官方课程库」。改完是**把界面收回到代码本来就在用的词**，不是造新词。

计数「N 门课程」不动：「官方课程库 · 3 门课程」是自然说法，改成「3 个库」反而丢了信息。

## 四、反证（3/3 真红，逐字节还原）

`shutil.copy2` 备份 + 还原，三段 sha256 前 12 位逐一比对一致：

| 破坏 | 结果 |
|---|---|
| 眉题退回「官方公开知识库」 | 红（与后端 source 不同词） |
| 后端 source 退回「官方资料库」 | 红 |
| 详情页副标题退回旧词 | 红 |

★ **第一版反证跑出了假绿**：脚本按 `官方课程库` 整个词替换，命中的是文件顶部
那段说明注释（注释会被 `_code()` 剥掉，眉题根本没被改），于是"反证"是绿的。
锚点收紧到 `<span className="eyebrow">官方课程库</span>` 才真红。
—— 反证本身也要检查"我到底改到了哪一行"，否则它只是又一层假验证。

## 五、还欠着

- 后端改的是**展示串**，`official` 布尔判定没动，接口契约不变；但 `source`
  是拼好的中文字符串，**跟着界面词走**，以后界面上再改名它必须一起改
  （现在有守卫钉住了）。
- `_official_kb_or_404` 的 404 文案也顺手从「官方资料库不存在」改成
  「官方课程库不存在」。同文件其他 `知识库不存在：{kb_id}` 没动 ——
  那是后端命名，不属于这次界面定名。
- 没上真机（老规矩）。
