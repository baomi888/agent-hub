## B3. 申报作品情况（科技发明制作）

### 作品设计、发明的目的和基本思路，创新点，技术关键和主要技术指标

**一、目的**
当前大学生在课程学习、考研备考、论文写作等场景中，普遍面临"资料零散难检索、问答无可靠出处、学习工具分散"的痛点。本项目面向高校学生，构建一套可私有部署的一站式智能体平台，将 RAG（检索增强生成）知识库、多轮对话 Agent 与校园实用工具整合于一体，并始终坚持"辅助学习而非替代思考"的 AI 素养导向。

**二、基本思路**
团队先通过问卷调查大学生真实需求（已回收有效问卷，见佐证材料），据此设计"前端体验—后端服务—向量检索—智能体编排"四层架构：以 FastAPI 提供全链路 SSE 流式服务，以 Next.js 实现"苞米地笔记本"风格的用户界面；通过多用户强隔离机制保证数据安全与账号独立。

**三、创新点**
1. **模板广场**：提供考研、论文、期末、求职、四六级、社团、文献等 8 类校园场景模板，以"教搭建而非代做"的方式降低上手门槛，强化学生 AI 素养；
2. **强数据隔离的多用户架构**：按 owner 强制隔离，归属校验失败返回 404 而非 403，从根本上避免越权访问与数据混淆；
3. **RAG 三段式重排检索**：候选池扩召回 → 余弦离群过滤 → MMR 多样性去重，在 top-k 名额有限时显著提升引用质量；
4. **苞米地独特 UI 设计语言**：手绘吉祥物 + 暖米黄纸视觉风格，区别于千篇一律的通用 SaaS 后台；
5. **零门槛校园工具集**：GPA 分析、课程表、群抽签等纯前端工具，无需登录即可使用。

**四、技术关键**
异步 FastAPI 与手写 StreamingResponse 实现流式响应；LangChain v1 编排 Agent 五工具（知识库检索、联网搜索、计算、天气、下载入库）；Chroma 进程级单例保证多知识库隔离；SQLite WAL 模式参数化存储与窗口截断。

**五、主要技术指标**
检索 top_k=3、MMR 多样性权重 λ=0.65、余弦相似度下限 0.25；实测只读接口 8 并发 P50≈34ms，SSE 问答 3 并发端到端≈1.64s，文档上传 3 并发≈2.78s。

### 作品的科学性、先进性（须说明与现有技术相比的突出实质性技术特点和显著进步，附参考文献）

与通用对话工具（如 ChatGPT 及国内大模型网页版）相比，本作品具有三点实质性进步：① 所有回答均带可点击的原文角标，可回溯至知识库片段，解决了"AI 凭空编造"的学术诚信痛点；② 支持私有知识库隔离，资料不出个人、不出校；③ 多用户数据强隔离，适配校园多账号共用场景。与通用 RAG 框架相比，三段式重排（扩召回 + 离群过滤 + MMR）在 top-k 名额有限时有效避免相邻重复切片占满名额，提升引用的相关性与多样性。平台遵循主流软件工程规范：分层架构、集中配置校验、结构化日志、JWT 短时效访问令牌 + 服务端刷新令牌、配额与限流防护。

## C. 当前国内外同类课题研究水平概述

近年来，检索增强生成（RAG）与 AI 智能体（Agent）技术发展迅速，已成为大模型落地的主要范式。国外以 LangChain、LlamaIndex 等框架为代表，国内大模型厂商也纷纷推出对话与知识库产品。然而，现有通用工具普遍存在三点不足：回答无可靠出处、知识库无法私有隔离、缺乏面向特定人群的学习素养引导。本项目在此基础上，以"学习素养导向 + 多用户强隔离 + 校园场景化"为差异化定位，针对高校学生这一具体群体提供一体化解决方案。相关综述与框架文档可佐证该技术路线的成熟度与本项目增量价值。
