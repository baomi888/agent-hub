### 结构重构

- `kb/importer.py`：`import_url`（抓网页）与 `download_and_index`（下载文档）的后段重复（加锁→去重→加载→切片→校验→写向量→登记）抽成 `_index_into_kb()`。
  **刻意保留的差异**：两处"切片为空"的报错文案不同（"URL 内容切片为空" / "文档内容切片为空，无法入库"），作为参数传入而不合并——那段文案直接展示给用户。
- `kb/rag_core.py`：`_source_meta()` 同时消除了"强度阈值判断写两遍"的隐患（原两处注释都要求同步维护）。

### 行为变更（两处既有缺陷，已单独确认后修复）

| 缺陷 | 修复前 | 修复后 | 影响面 |

## 四、边界与异常分支覆盖

- 上传：空文件列表 / 非法 mode / 非法扩展名（且断言一个字节都没落盘）/ 非属主 404 / 中途第二个文件失败
- 检索：空候选 / 候选不足 top_k / 三元组入参（带 rank）/ 距离越界不可换算 / `distance=None`
- 格式化：空结果（`（无检索结果）`）/ 缺 page / 相似度不可换算时整段省掉 `score=`
- 流式：会话不存在 404 / 无历史时不发改写帧 / `done.run_id=None` 等字段集合
- 画像偏置：无画像不动 / 双向包含匹配（`|数学|` 与 `|数学分析|`）/ 无重合保持原序
- 天气：缺城市与坐标 / 天数 0 与 8 / 无高德 Key 的坐标路径兜底

## 六、遗留风险

- 「每 16 帧查一次断连」把"客户端已断开"的感知从逐帧推迟到最多 15 帧；对断连侧的响应清理
  会晚几十毫秒（正常连接完全无感知）。
- `_source_meta()` 与 `build_sources`/`_format_refs` 现在共享阈值口径，但**阈值本身**
  （`RETRIEVE_LOW_SIM=0.45`、`RETRIEVE_MIN_SIM=0.25`）仍是行为红线，改动会直接改变"强/中/弱"
  标注与是否示弱，需配套更新基线断言。
- embedding 线程池改为进程内复用后不再随入库结束回收；常驻线程数上限为 `EMBED_CONCURRENCY`。
