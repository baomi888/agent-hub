# 前端整改验收标准 Checklist

> 按此逐项执行与自查，每条可勾选 ✅ / ❌，❌ 需记录原因。
> 目标方向：极简对话流（类 Kimi/豆包）+ 专业功能「始终可见但排版更友好」。

## A. 中文化（用户可见处不留英文术语）

- [ ] `top_k` → 「检索条数」，下方有「AI 每次从资料里取几条最相关的」说明
- [ ] `chunk_size` → 「分段长度」，说明「资料切多长的片段」
- [ ] `chunk_overlap` → 「重叠字数」，说明「相邻片段重叠多少字」
- [ ] 模式 `Agent` → 「智能体」（可加小字备注「可调用工具」）
- [ ] `txt/md/pdf` → 「Word / PDF / 记事本 / Markdown」
- [ ] 知识库标签 `知识库 · {id}` → 显示中文名（或中文别名）
- [ ] 后端返回的 `chunks` 等英文字段在界面全部映射为中文
- [ ] 全局搜索：界面无残留裸英文变量名（`top_k`/`chunk_size`/`kb_id` 等）

## B. 配色语义化

- [ ] 主操作（新建会话、发送、绑定）→ 蓝色，且全局一致
- [ ] 成功态（已绑定、导入完成）→ 绿色
- [ ] 删除/危险（删会话、删库）→ 红色
- [ ] 中性/次要按钮 → 灰色
- [ ] 无随机紫/蓝/绿混用（模式按钮、导入按钮全部语义化）

## C. 极简对话流（中间区）

- [ ] 顶部「参数设置」占位行移除，参数下沉到输入区旁「⚙ 设置」或折叠面板
- [ ] 模式切换移到输入框上方一条，或输入框内，不抢占主视觉
- [ ] 底部为大圆角输入框 + 明确「发送」按钮，Enter 发送 / Shift+Enter 换行保持
- [ ] 消息气泡排版不变或更佳，正文 15px、行距舒展

## D. 资料库面板（右侧，始终可见但友好）

- [ ] 主列表「我的资料库」置顶，显示中文名 + 片段数
- [ ] 上传文档 / 联网导入收进「+ 导入资料」分组，默认折叠、点开才展开表单
- [ ] 每个功能区之间有清晰视觉分隔（卡片分区），不再三块平铺堆叠
- [ ] 「解绑当前」按钮语义化、位置合理

## E. 体验细节

- [ ] 毛玻璃卡片描边 + 投影增强，浅色背景下层级清晰
- [ ] 无会话空状态给出「先导入资料 → 再提问」两步引导
- [ ] 无知识库空状态同样给引导，而非仅一句「暂无知识库」
- [ ] 参数区改为「每行：中文名在上、通俗说明在下」

## F. 功能回归（改动不得破坏既有能力）

- [ ] 新建 / 切换 / 重命名 / 删除会话 正常
- [ ] 绑定 / 解绑知识库 正常并即时刷新
- [ ] SSE 流式问答：状态帧→逐字 token→工具卡→引用资料→done 完整
- [ ] 四种模式（自动/检索/智能体/纯对话）切换生效
- [ ] 上传文档建库、联网搜索预览、勾选导入 正常
- [ ] 删除知识库 正常
- [ ] `npx tsc --noEmit` 通过，`next dev` 无报错

## G. 技术验证项（动手前先做）

- [ ] 验证 Chroma collection 是否支持中文/空格 id
  - 支持 → kb_id 直接中文化
  - 不支持 → 内部英文 id + 前端中文别名（新增 `name` 字段映射）
- [ ] 确认后端 API 返回字段是否需补中文名映射（前端映射即可，不动后端）

## H. 端到端验收（最终）

- [ ] 刷新 http://localhost:3000 页面正常渲染、无控制台报错
- [ ] 走一遍完整链路：导入资料 → 绑定 → 提问 → 流式回答 → 引用展开
- [ ] 在手机/窄屏或缩放窗口下布局不崩

### 执行顺序

1. **A→B→C→D**（低风险快见效）
2. **E→F**（收尾回归）
3. **G**（动手前先验证）
4. **H**（全链路验收）
