## 二、为什么要花这笔钱

### 1. 项目现状

知穗 Agent 目前是一个已上线运行的 Web 系统，包含 AI 对话、学习路径、论坛、打卡、
资料库等 14 个功能模块，部署在 `myzhisui.cn`，已有真实用户在使用。

### 2. 下一步目标

将其打包为 iOS 原生 App，使团队成员与指导老师可以直接安装在 iPhone 上使用，
并作为项目的正式成果对外展示。

### 3. 苹果的技术限制（这是支出产生的根本原因）

苹果公司对 iOS 生态实行强制签名制度：**任何应用程序要安装到非越狱的 iPhone 上，
必须由 Apple 签发的开发者证书签名。** 没有该证书：

- 应用无法安装到任何一台他人的 iPhone 上
- 无法提交至 App Store
- 无法使用 TestFlight 分发测试

这不是可选的商业服务，而是苹果封闭生态的准入条件，**在 iOS 平台上没有替代方案**。

### 4. 688 元买到的是什么

| 能力 | 说明 |
|---|---|
| Ad Hoc 分发 | 最多 100 台设备，通过链接直接安装，无需经过应用商店审核 |
| TestFlight 内测 | 最多 100 名内部测试员，同样无需审核 |
| App Store 上架资格 | 免费应用上架不额外收费，无需再支付任何费用 |
| 推送、内购等系统能力 | 免费账号不具备 |

以上能力合并在同一笔年费内，不按项计价。

## 三、为什么不用免费方案（已逐一核实）

| 替代方案 | 费用 | 不可行的原因 |
|---|---|---|
| 免费 Apple ID + Xcode 签名 | 0 | 仅限 3 台设备，**签名 7 天过期**，需每 7 天用电脑重新签一次；团队 5 人分散在不同地点，无法持续维护；且不支持推送 |
| 企业证书（In-House） | 2,088 元/年 | 更贵；需公司实体与 D-U-N-S 编码，学生团队不具备资格；苹果对滥用查处严格，证书被封将导致所有用户**同时无法打开应用** |
| 学校名义申请会费豁免 | 0 | 苹果确有政策（Fee Waiver），但要求以**学校法人**名义注册，需 D-U-N-S 编码、学校域名邮箱、法人授权，审核周期 2–6 周且苹果有权拒绝。**已同步向学院咨询是否有现成账号**，但答复前不能作为交付依赖 |
| PWA（网页添加到主屏幕） | 0 | 目前已在使用，但它不是应用程序：无应用商店页面、不进入「iPhone 储存空间」、推送受限，无法作为项目成果交付 |
| 安卓 APK 直接安装 | 0 | 安卓允许自由安装，iOS 不允许。两者的分发规则完全不同，无法互相替代 |

## 六、支出的性质说明

**该费用为年费订阅，非一次性买断。** 具体规则：

- 首年 688 元，有效期 12 个月
- 到期后如项目继续运营，需按年续费；如项目结束，可不续费
- 停止续费的后果：已上架应用将被下架，通过 Ad Hoc 安装的应用将无法打开
- 中途取消订阅，已支付年费不予退还

因此建议按「一年期项目成本」列支，而非一次性设备采购。
