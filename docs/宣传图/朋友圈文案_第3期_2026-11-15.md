### 写这几版时刻意做的事

- **待办放第一位，且写"由你定"不写"自动帮你加"**：`/api/capture/parse` 只出建议、
  不写库，必须用户勾选再提交。文案写「你勾哪条才写进待办」——这是产品的实际行为，
  也是它跟"AI 一键生成"那类宣传的分界线。
- **三个名字不混**：广场叫「公开知识库」，广场里官方自建的那一区叫「官方知识库」，
  我自己的库叫「资料库」。界面与文案同一套词（命名守卫扫 `frontend/src` 全部 ts/tsx）。
- **参数代替形容词**：「9 个库 / 73 份 / 6 个板块 / 9 张图 / 提前 20 分钟 / 每行约 19.4 字」
  都能核对；「很顺手」「再也不用折腾」不能核对，删掉。
- **数字是现场数的**：9 个官方库与 73 份文件来自线上 `data/kb_public.json` +
  `data/kb_files.json`（9 条 `official && on`，逐库文件数相加 = 73），不是估的。
- **不编数字**：不写「上万同学在用」「效率提升 300%」。
- **不用产品腔**：「赋能 / 一站式 / 助力 / 体验升级 / 焕新」一个都没有
  （公告那一侧有 `test_no_product_weekly_speak` 直接查）。
- **不用口语腔**：「呀 / 啦 / 嘛 / 都行 / 随便 / 顺手 / 不用」也不用
  （公告那一侧有 `test_copy_reads_like_a_release_note_not_a_chat` 直接查）。
- **只说用户能感知的**：内部重构、死代码清理、并发部署这些一个字都不提。

## 四、这张图怎么复现 / 改字

```bash
# 1. 改 docs/宣传图/知穗_11月更新_第3期_源文件.html 里的字
# 2. 截图（Edge 无头，1x 与 2x 各一次）
MSYS_NO_PATHCONV=1 "/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" \
  --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1080,1440 --screenshot=".../知穗_11月更新_第3期_朋友圈_1080x1440.png" \
  "file:///E:/项目资料/苞米agent/docs/宣传图/知穗_11月更新_第3期_源文件.html"
```

- `--force-device-scale-factor=1` 就是 1 倍图；要 2x 把它改成 `2`，
  文件名带 `@2x`。**不要**用 `--window-size=2160,2880` 代替 —— 那是放大版面，不是提高分辨率。
- 改完必须 `PIL` 核一次尺寸（1080×1440 / 2160×2880），别只信"文件生成成功"。
- 二维码图片是 `qr_myzhisui.png`，就在同目录；换域名要重新生成并**反解验证**再发。
- ★ 版面是 `justify-content: space-between` 分空白的：**改了一格的文字行数，整页会重排**，
  所以改完必须重看一遍三格是否还等高、底部留白有没有塌到一坨。
- ★ 「三格齐不齐」用眼睛看会误判（阴影会骗人）。用
  `.workbuddy/tmp/_measure_poster2.mjs` 读三格 `getBoundingClientRect().bottom`，
  实测差 0 才算齐；它同时量标题（Range 取文本宽，不比元素宽）与格内 `scrollHeight`，
  能一次抓住"标题折行 / 内容顶破格高"这两类错。
- ★ 说明文字每行**别超过 14 个汉字**（244px 宽 / 16px 字号）：15 个字会把最后一个字挤到
  下一行，看着像排版事故。这版第一稿三格全是这种孤字，重写过一次。
