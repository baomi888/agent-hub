## 一、朋友圈正文（三个版本）

### 版本一（推荐）

微信朋友圈超过 6 行会折叠成「全文」，所以**前两行必须是钩子**。三件并起之后，
钩子不能再只写论坛，要一口气把三件说完。

```
知穗 · 十一月更新（第 3 期）

这周上了三样东西：论坛、待办、官方课程库。

论坛：六个板块，问课、求资料、找人一块自习，一句话一张图都能发。
待办：不用一条条填了。跟它说一句「明天下午三点交高数作业」，
它自己整理成待办和该提醒的时刻，课表也自动排进去。
课程库：九门课、73 份真题讲义答案，在线翻也能下载，公式不再是乱码。

还顺手上了：边说边出字的语音、手机上少找两步。

myzhisui.cn
```

### 写这几版时刻意做的事

- **三件并起就三件都写**：不再让论坛独占第一句、其余三条退成脚注。
  用户明确说过优先级是「论坛 = 待办 > 课程库 > 其他」，文案与海报都按这个来。
- **待办写"说一句"而不是"提醒会响"**：前者是这周真正做出来的东西
  （一句话 → 整理 → 勾选 → 写入），后者只是它的一部分。课表联动单独点名一句。
- **不编数字**：不写「上万同学在用」「效率提升 300%」。「9 门课 / 73 份」是库里的实数。
- **不用产品腔**：「赋能 / 一站式 / 助力 / 体验升级」一个都没有（公告与文案同一份禁用词表，
  有测试查）。
- **只说用户能感知的**：内部重构、死代码清理、并发部署这些一个字都不提。
- **主亮点变了就重排，不是加一条**。这一期从"论坛一个主角"改成"三件并起"，
  所以主标题、海报版面、文案第一句一起换了。

## 三、发布建议

- **时间**：周日晚 20:00–21:30（宿舍在线率最高，也是"下周要交作业"的焦虑点）。
- **配图顺序**：三图是「1 + 2」排布 —— 主海报必须放第一张，它决定别人点不点开。
- **第一条评论**放链接与一句「三样都在，扫码就进」：正文里放链接会被折叠吃掉。
- **不要**在班级群 / 年级群连发同一张图；群发用口语版（`群发文案_口语版_*.md` 那套），
  并且一次只发一个群。
- 有人问「资料能商用吗」→ 统一回：课程资料只做校内学习参考，出处以库内说明为准。

## 四、这张图怎么复现 / 改字

```bash
# 1. 改 docs/宣传图/知穗_11月更新_第3期_源文件.html 里的字
# 2. 截图（Edge 无头，1x 与 2x 各一次）
MSYS_NO_PATHCONV=1 "/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" \
  --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1080,1440 --screenshot=".../知穗_11月更新_第3期_朋友圈_1080x1440.png" \
  "file:///E:/项目资料/苞米agent/docs/宣传图/知穗_11月更新_第3期_源文件.html"
```

- `--force-device-scale-factor=1` 就是 1 倍图；要 2x 把它改成 `2`，
  文件名带 `@2x`。**不要**用 `--window-size=2160,2880` 代替 —— 那是放大版面，不是提高分辨率。
- 改完必须 `PIL` 核一次尺寸（1080×1440 / 2160×2880），别只信"文件生成成功"。
- 二维码图片是 `qr_myzhisui.png`，就在同目录；换域名要重新生成并**反解验证**再发。
- ★ 版面是 `justify-content: space-between` 分空白的：**改了一格的文字行数，整页会重排**，
  所以改完必须重看一遍三格是否还等高、底部留白有没有塌到一坨。
