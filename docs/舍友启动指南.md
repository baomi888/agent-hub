# 舍友启动指南（知穗 Agent 本地跑起来）

这份是专门给你（舍友）看的，照着做就行，不用懂原理。

---

## 一、先确认你拿到的东西

知穗用 `git clone https://github.com/baomi888/agent-hub.git` 把整个仓库拉到你电脑后，
会生成一个 `agent-hub` 文件夹。里面主要是：

- `main.py` + `core/` `kb/` `agent/` `api/` —— 后端（Python/FastAPI）
- `frontend/` —— 前端（网页界面，Next.js）
- `prototypes/` —— **两个 HTML 文件，双击就能看效果，不用跑任何环境**（见第五节）
- `.env.example` —— 配置文件模板（⚠️ 不是真正的配置，必须换成真实的）
- `start.bat` —— **一键启动器**，双击它就能把前后端都跑起来

---

## 二、先装两个环境（只需一次）

### 1. Python 3.10 或更高
- 下载：https://www.python.org/downloads/ （选 3.10+ 版本）
- 安装时**务必勾选 "Add python.exe to PATH"**（最下面那个框），否则后面命令找不到 python

### 2. Node.js 20 或更高
- 下载：https://nodejs.org/ （选 LTS 版，20 以上）
- 装完后在命令行输入 `node -v` 能看到版本号就算成功

> 验证：打开「命令提示符」（Win+R 输入 cmd），分别输入 `python --version` 和 `node -v`，
> 都能显示版本号再继续。

---

## 三、最关键的一步：放好 `.env`（缺一不可）

代码跑起来需要 API 密钥，**知穗会把真实的 `.env` 内容通过微信私发给你**。
你拿到后这样做：

1. 进入 `agent-hub` 文件夹
2. **新建一个文件，名字就叫 `.env`**（注意前面有个点，没有后缀）
   - 小技巧：在文件夹里按住 Shift 右键 →「在此处打开终端」，输入 `notepad .env` 回车，
     记事本就让你可以创建这个带点的文件
3. 把知穗发给你的内容**整段粘贴**进去，保存

⚠️ **绝对不要**只复制仓库里的 `.env.example` 然后不改就当 `.env` 用——
那个文件里的 `DEEPSEEK_API_KEY=在此粘贴...` 是占位文字，不换成真实密钥一定跑不起来。

`.env` 里这 3 个是必填的（知穗发你的版本里已经是填好的真实值）：
- `DEEPSEEK_API_KEY` —— 对话模型
- `EMBEDDING_API_KEY` —— 文档向量化
- `EMBEDDING_BASE_URL` —— 向量化服务地址

其余都已经有默认值，不用动。

---

## 四、一键启动

1. 进入 `agent-hub` 文件夹
2. **双击 `start.bat`**
3. 会弹出：
   - 一个紫色字体的启动窗口（自动装依赖、启动服务）
   - 两个黑色命令窗口（一个是后端、一个是前端）—— **这两个别关！**
4. 等约 8 秒，浏览器会自动打开 `http://localhost:3000`

看到网页就是成功了 🌽

### 注册登录
- 首页点注册，随便起个用户名和密码（默认允许自助注册）
- 登录后就能建知识库、上传文档、聊天

## 五、只想看 UI 效果，不想配环境？

仓库里 `prototypes/` 文件夹有两个 HTML，**双击用浏览器打开就能看**，零环境、零密钥：

- `prototypes/校园工具集.html` —— 6 个小工具 + 仿小律课程表（最直观）
- `prototypes/平台预览.html` —— 4 模块平台预览图

这两个是给产品演示/看设计用的，不是真功能，但能让你秒懂这个项目长啥样。

## 六、跑不起来？按这张表排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击 start.bat 后黑窗口一闪而过 / 立即关闭 | 没装 Python 或没勾选 PATH | 重装 Python，确认勾选 Add to PATH |
| 启动窗口红色报错「未检测到 Python」 | 同上行 | 同上 |
| 浏览器打不开 localhost:3000 | 前端还没起好，或端口被占 | 等久一点；关闭占用 3000 端口的程序再试 |
| 网页能开，但聊天答不出 / 报错 401 | `.env` 没放好或 key 不对 | 确认 `.env` 在 `agent-hub` 根目录、内容是知穗发的真实值 |
| 后端黑窗口里出现 `缺少 DEEPSEEK_API_KEY` | 没建 `.env` 或没填 key | 回到第三节 |
| `npm install` 报错 | Node 版本太低（需 20+） | 升级 Node 到 20+ |
| `pip install` 很慢或失败 | 网络问题 | 可加镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |

### 想看具体报错（进阶）
如果不走一键启动，可以手动分步跑，报错会更清楚：

```bash
# 后端（在 agent-hub 目录下，开一个终端）
pip install -r requirements.txt
python main.py
# 另开一个终端，看 http://localhost:8000/health 是否返回 {"status":"ok"}

# 前端（在 agent-hub/frontend 目录下，再开一个终端）
npm install
npm run dev
# 浏览器开 http://localhost:3000
```

## 七、停止服务

直接关掉那两个黑色命令窗口即可。下次想用再双击 `start.bat`。
