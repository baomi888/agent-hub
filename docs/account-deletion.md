# 先跑通账号注销这一条路径

本轮范围：后端清理服务、维护入口和隔离测试。没有执行已有用户的实际注销，没有上线公开注销按钮。

## 当前确定的规则

- 不自动合并账号，不抢占他人绑定。允许更换绑定：先确认解绑原微信，再明确绑定新微信。
- 解绑保留内部账号和数据，必须先设置本站密码。只有安全邮箱也不能直接解绑。
- 注销删除内部账号、全部第三方关联及可追溯的在线业务数据。无密码账号同样可以注销。
- 微信和支付宝登录都在查到关联后检查内部账号是否启用，签发登录态之前再核对账号。支付宝已完成离线接线和测试，真实平台联调仍待后续进行。

## 这一步只学两个东西

**数据归属**：找到 `users.id` 对应的业务行，还要沿着会话 ID、提醒 ID、话题 ID 找到没有用户字段的子记录。不能只删 `users`，也不能只搜索名为 `user_id` 的列。

**失败后的重试**：数据库和文件不是同一个事务。先在数据库事务内删除业务行并保存清理清单；提交之后处理调度库、向量库和文件。处理成功才标记 `done`。失败时保留 `pending`，按同一个 uid 继续清理，不恢复账号。

代码阅读顺序：`core/account_deletion.py` 的 `purge()` → `_delete_rows()` → `_purge_files()`。其余是归属收集和路径校验，暂时不必逐行学习。

## 本轮清理范围

| 数据 | 处理 |
| --- | --- |
| 账号、邮箱、微信／支付宝等关联、在途第三方授权 | 删除；无需先设置密码 |
| 验证码、待消费邮箱凭证 | 按 context 中的内部用户 ID 删除 |
| 会话、消息、压缩摘要、消息反馈 | 删除本人会话及子记录 |
| 个人资料、任务、专注、学习、打卡、提醒、画像、用量、订阅等 | 按现有各表的 owner_id、user_id、uid 等归属列删除；提醒触发记录单独关联删除 |
| 话题、回复、点赞、收藏、关注、通知、举报 | 删除本人记录及相关子记录；本人发起的话题沿用原论坛规则，连同楼内回复删除 |
| 用户反馈及回复 | 删除本人反馈的整条链路及本人署名回复 |
| Prompt 回放集、评估快照 | 按本人消息生成的 case_key 清理回放样本和相关评估；全局提示词配置保留并清理本人创建者标识 |
| 调度记录 | 清理以本人 uid、本人委托 ID、上传任务 ID 为 subject 的记录 |
| 本人资料库 | 严格删除 Chroma collection、四份 JSON 登记和原始文件；错误必须报告，不能吞掉 |
| 上传、下载、自定义头像、论坛图片 | 清理有归属记录的文件及本人当前头像／已发布帖子配图；内容去重的图片仍被他人使用时保留共享文件 |
| 账号安全 audit.log | 清除本人事件；保留其他用户事件 |
| 注销凭证 | 保留最小 uid 墓碑，拒绝旧 JWT；任务成功后清空文件清单，不留原用户名、邮箱和第三方标识 |

普通行按现有表结构的归属列清理，复杂子表显式清理。以后新增模块，如果使用不同的归属字段或新的外部存储，必须把清理规则一并接进来。

## 必须说清的边界

1. **这是停机维护入口。** 运行前必须停止 API、worker 及其他写入进程，并避免同时执行其他维护操作。当前进程内的 KB 锁不能约束独立 worker，也不能阻止已经通过鉴权的请求继续写回；不能直接把本服务挂到 HTTP 路由。后续接线上按钮时，需要额外实现身份复核、跨进程写入协调和结果提示。
2. 历史聊天附件没有保存上传者，甚至未在消息表保存附件路径。无法可靠反推出用户的旧附件不会猜测删除。新上传的聊天附件、论坛图片和头像已经写入 `owned_uploads`，以后即使没提交到聊天／帖子，也能追溯上传者。
3. 逻辑删除当前在线业务数据不等于磁盘取证级擦除。历史备份、外部平台持有的数据、代理访问日志及无法追溯到账号的旧文件不在本入口范围。验证码的加密散列限流桶和系统级聚合配置保留。
4. 删除的是本站保存的微信／支付宝关联，不是注销用户在微信／支付宝的账号。本站清理完成后再次扫码会重新查关联；没有关联便按新用户规则处理，仍受开放注册开关等规则约束。

## 如何验证

只运行隔离测试，环境中的项目依赖和 pytest 需已安装：

```powershell
python tools/run_isolated_tests.py tests/test_account_deletion.py tests/test_wechat_login.py -q
```

测试链路：无密码微信用户 → 创建聊天、学习等测试数据 → 注销 → 检查其他用户保留、旧令牌失效 → 原微信再次扫码创建新内部用户。另测数据库回滚、文件失败重试、向量库失败重试、路径穿越拒绝，并在临时目录验证真实 Chroma collection 删除。微信 HTTP 和向量库故障使用模拟响应；不连接真实微信。

## 维护入口

默认仅预览直接归属行的计数，不删除；子表最终由清理服务关联处理：

```powershell
python tools/purge_account.py --uid <本站用户ID>
```

实际执行必须先完成停机和数据备份，并明确指定同一个用户 ID：

```powershell
python tools/purge_account.py --uid <本站用户ID> --apply --confirm-uid <本站用户ID> --writers-stopped
```

标志是维护人员的显式确认，不会自动检测或停止进程。保持写入进程停止，直到清理完成后再启动。只有整条清理链路完成才输出“账号注销完成”；失败返回非零退出码，不能当作成功。修复存储或登记文件问题后，用同一个用户 ID 重试；成功任务重复执行无副作用。
