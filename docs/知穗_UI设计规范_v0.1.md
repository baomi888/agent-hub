> 所有令牌值**照抄 `frontend/src/app/styles/tokens.css`**，不凭记忆写；类名照抄 `components.css`、图标照抄 `CornIcon.tsx`。

## 0. 三条铁律（违反即返工）

| # | 铁律 | 说明 |
|---|---|---|
| **1** | **全站禁用 emoji 与字符图标** | 界面里不得出现 `🎒 ✎ ✕ ✅ ⚠ ＋ → ★ …` 这类 emoji / 花体字符充当图标。一个都不行。 |
| **2** | **图标一律走 `CornIcon` 手绘风** | 与「知穗吉祥物」同一套语言：`currentColor` 粗描边、圆头圆角、玉米金点缀。不许引入第三方向标库（lucide / heroicons / feather 等）。 |
| **3** | **金色只做点缀** | 金 = 「选中的 / 这是主操作」；hover / focus 一律中性色（`--fill-*`），**不用金色表示"鼠标在上面"**。浅底小字用 `--accent-ink`，不用 `--accent`。 |

> 禁忌（历史教训，别再犯）：荧光黄、粗黑描边、直角、深色大面积、玻璃拟态、白色高光线/高光圆球。

## 1. 设计说明

### 1.1 用户与任务
大学生用户，在**备考 / 求职**两个场景里，把学习资料、对话、工具集中到一个工作台上。核心任务只有一件：**让知穗读懂自己的资料并给出可追溯的回答**。

### 1.2 页面主动作（每个页面只允许一个"实色主操作"）
| 页面 | 主动作 | 主操作样式 |
|---|---|---|
| 首页 / 对话 | 开始提问 | 输入框发送（深棕墨实心） |
| 侧栏 | 新建对话 / 导入会话 | `.btn-new`（**深棕墨实底**，hover 才转金） |
| 知识库面板 | 喂资料（上传 / 联网） | `.btn-import`（描边 + `::before` 金点） |
| 工具集 | 打开某个小工具 | 卡片整块可点，不加按钮 |
| 设置 / 委托 / 总结 / 打卡 | 保存 / 提交 | 同 `.btn-new` 实心 |

### 1.3 视觉关系（层级靠什么分区）
- 明度只有**三级**（`--step-0/1/2`），面板与画布**同处一档**，这一层的分界交给 **1px 描边**，不靠明度差。
- 「抬起」只靠 `--shadow-1`（贴纸薄卡）/ `--shadow-2`（浮层）两档，**不出现重投影**。
- 圆角四档 `xs/sm/md/lg`，胶囊 `999px`、正圆 `50%`，**不许出现直角**。

### 1.4 关键状态（每个交互件必须定义全）
每个可交互元素都要给出：**默认 / hover / active / focus-visible / disabled**。
每个数据区域都要给出：**空状态 / 加载中 / 错误**（见 §5）。
> 空状态统一「玉米线描插画 + 一句引导」，**不用 emoji**；加载用现成 `.skel-block` 骨架；错误用**气泡/内联**，不用全局弹窗。

## 3. 图标系统 `CornIcon`

文件：`frontend/src/components/CornIcon.tsx`（`viewBox="0 0 48 48"`，`stroke="currentColor"`，`strokeLinecap/Join="round"`）

- **描边**：继承 `currentColor`（调用处外层 `color` 决定，一般是墨色）→ hover 变色、深浅底自动适配。
- **点缀填色**：玉米金 `#F5B840` 主填；叶绿 `#7C9A54/#8FAF62`、陶橙 `#EF8A56`、纸白 `#FFFDF6` 辅助。
- **形态**：粗描边、大圆角、Q 版手绘，**无直角锐角**。
- **兜底**：未知 `name`（含历史残留 emoji）一律回退 `corn`（mini 知穗），**保证永不显示成系统 emoji**。

**现有 27 个 name**（按用途分组）：
- 场景：`book` 考研复习 · `pen` 论文写作(笔尖) · `notes` 课程笔记 · `bolt` 期末冲刺 · `briefcase` 求职简历 · `globe` 四六级/雅思 · `target` 社团策划 · `search` 文献阅读
- 功能：`store` 模板广场 · `tools` 校园工具集 · `bulb` 理念提示 · `warn` 警告 · `info` 提示
- 操作：`plus` 新增 · `pencil` 编辑 · `trash` 删除 · `close` 关闭 · `check` 确认 · `refresh` 重来 · `upload` 上传 · `download` 下载 · `link` 外链
- 元信息：`clock` 倒计时 · `calendar` 日期 · `star` 收藏 · `user` 账号 · `settings` 设置
- 兜底：`corn` mini 知穗

**用法**：`<CornIcon name="trash" className="h-5 w-5" />`
新增图标时：① 沿用同一 `INK_STROKE`；② 主色填 `#F5B840`；③ 注册进 `ICONS` 与 `CornIconName` 联合类型；④ **同步更新本表**。

## 5. 页面级约定

### 5.1 三栏骨架
`Sidebar`（左 · 会话）｜`ChatArea`（中 · 对话）｜`KnowledgePanel`（右 · 资料库）。
断点：**wide**（≥1024 三栏常驻）· **mid**（右侧抽屉）· **narrow**（两侧皆抽屉 + 遮罩）。

### 5.2 空 / 加载 / 错误
- **空**：玉米线描插画 + 一句引导动作（如"还没对话，问一句试试"），无 emoji。
- **加载**：`.skel-block` 骨架，尺寸与真实内容一致（避免跳动）。
- **错误**：内联/气泡级提示；**429 要翻译成人话**——`api.ts` 会把 `retry_after` 拼成"（约 N 秒后可重试）"，配额超限直接用后端「每日问答已达上限…」文案。

### 5.3 移动端
- **触控目标 ≥ 44×44**（iOS HIG；比早期写的 40 更宽）。图标按钮视觉上可以只有 20px，
  但热区要用 `padding` 或伪元素撑到 44；相邻目标间距 ≥8px。
  **视觉尺寸 ≠ 热区**——参考开关的做法：元素本身 44×44，轨道用 `::before` 画成 44×26。手机上没有"悬停"可补救，点不中就是点不中。
- **底部 Tab 优先于汉堡抽屉**（新四屏）：对话 · 委托 · 总结 · 打卡 · 我的。一次点击到位；
  需要用户**天天看见**的页面藏进抽屉里，等于不存在。
- **表格一律卡片化**，明确否决横向滚动：看不到右边，用户就不知道右边还有内容。
- 会话左滑露出红色删除（`touch-action: pan-y`，滑过 1/3 吸附，须处理 `onTouchCancel` 复位）。
- Tab Bar 底部留 `env(safe-area-inset-bottom)`，否则被 iPhone 手势条压住；
  **输入框聚焦时 Tab Bar 收起**——键盘弹起后还留着它，提交按钮就被顶出屏幕了。
- 长表单的提交按钮**吸底常驻**（`position:sticky` + 渐变遮罩）：滚到底才能提交，是移动端最常见的弃单点。
- 欢迎页必须**一屏显示全**（logo + 场景卡 + 入口，短视口 `max-height:800px` 再缩一档）。

### 5.4 工程参数的白话表达（切片档位）

RAG 的 `chunk_size` / `chunk_overlap` 是实现细节。**禁止用裸数字输入框直接面向用户**——
用户不知道「500 字」是几段话，也无从判断该填多少。统一换算成三档「读法」：

| 档位 | 参数 | 适用资料 | 一句话 |
|---|---|---|---|
| 精细 | 300 / 60 | 名词解释 · 提纲 · 讲义 | 切得细，答得更准 |
| **均衡**（默认） | 500 / 50 | 教材 · 论文 · 通用文档 | 多数资料选这个就行 |
| 完整 | 1000 / 100 | 小说 · 访谈 · 连续文稿 | 切得整，上下文更连贯 |

- 数值只写在 `lib/chunkProfiles.ts` 一处，界面文案全部由它派生；后端契约不变（仍是 `chunk_size` / `chunk_overlap`）。
- **落点**：建库 / 联网导入的档位放**资料库面板**，并**按库各自记住**（`baomi.kbChunk.v1`，浏览器本地）；
  库列表用 `.tag` 回显档位名，「重新整理」沿用该库记录而不是全局值。
- 对话区齿轮**不再出现切片数字**，只留「每次回答参考几段资料？」（3 / 5 / 8 段 + 取舍说明），
  并在底部指明「资料怎么分段在右侧资料库按库设置」，避免用户找不到。
- 原始数字收进各自位置的「高级设置」，默认折叠；改数字即转为自定义档。
- 选中态 `border-accent + bg-accent-soft`；未选中 hover 走 `hover:bg-fill-2`（金只给持久状态）。

### 5.5 建完库后的下一步

导入成功后，资料库面板要给一句**内联引导**（不是一闪而过的 toast）：
「勾上它在列表左边的方框，回到对话框就能直接问里面的内容。」

用户卡住的地方常常不是"怎么建库"，而是"建完之后干什么"——参数再友好，也不如直接告诉他下一步。

### 5.7 四屏已落地成真页面（2026-10-13 夜）

设计稿 → 可跑页面：`/delegate`（P4）、`/report`（P5）、`/checkin`（P6）、`/settings`（P7）。
共用外壳 `components/console/ConsoleShell.tsx`（196px mini-nav + 登录门 + 用户 Context），
样式收在 `app/styles/console.css`。**桌面骨架不变**；移动端骨架见 §5.6（尚未落成页面）。

落页面时新立的四条约定：

| # | 约定 | 为什么 |
|---|---|---|
| 1 | **「接口未上线」要显式渲染成一块说明**，不能静默失败，也不能假装成功 | `/api/delegate`、`/api/report`、`/api/agent/tools`、`/api/schedule/*` 只在队友的 `feat/ai-module-20261013` 分支上，本分支跑起来 404。三态：`ready` / `absent`（端点不存在）/ `error`（真的挂了）—— 混在一起就会出现「后端没做」和「后端挂了」长一个样 |
| 2 | **演示数据必须挂「演示数据」标记** | 页面上有真数据（用量、资料库、账号）也有演示数据（委托列表、工具表），分不清就会把演示当结论 |
| 3 | **业务 404 不是错误** | `/api/report/{date}` 的「今日总结尚未生成」要渲染成「生成按钮」，不是红字报错。api 层用 `BusinessNotFoundError` 与「端点不存在」区分开 |
| 4 | 表单**常驻**在本页列内（不弹窗）；只有「预览生成内容」用一个只读浮层 | 沿用桌面稿的「左宽右窄、常驻不遮挡」 |

⚠️ **移植原型样式时的坑（本轮踩到）**：`prototypes/知穗_新页面设计稿.html` 在它自己的 `:root`
里定义了 `--gold / --paper / --leaf / --clay` 等品牌色，`tokens.css` **并没有这些令牌**。
`var(--gold)` 取不到值时，浏览器**整条声明作废、不报错** —— 总结页的活跃时段柱子、
设置页的用量条、打卡页的圆点曾全部静默消失。
落地原型样式前**必须先跑** `python tools/audit_css_tokens.py`，它会把「引用了不存在的令牌」全列出来。
另外 `--paper` 在 tokens 里别名指向 `--bg`（深色下是 #1A1610），**不能**当年用的「纸白」用 —— 那个位置要用 `--step-2`。

⚠️ **截图取证时的坑（同一个晚上踩到，更隐蔽）**：
主题只由 `app/layout.tsx` 里那段「文档加载时执行一次」的内联启动脚本决定，
它依次看 `?theme=` → `localStorage.theme` → **`prefers-color-scheme`**。
而 ① puppeteer 每次 `launch()` 都是全新临时用户目录，`localStorage` 是空的；
② 本机无头 Chrome 的 `prefers-color-scheme` 恰好报 **dark**。
⇒ **整轮渲染都是深色，所谓「浅色图」本来就是深色图**；
再加上「只 `localStorage.setItem('theme','dark')` 不重载」也不会重新应用主题（同文档内不触发
`storage` 事件，全项目无人监听），于是又产出 4 张与「浅色图」几乎字节相同的假深色图 ——
**两边全错、还互相"印证"，只比字节根本发现不了**。
所以截图脚本现在：显式用 `?theme=light|dark` 硬跳转钉住主题，并**断言实际渲染底色的亮度**
（浅色 `#F5F0E1` 亮度≈240、深色 `#211B11` 亮度≈32，阈值 150/100）。
**验主题不能只验 `<html>` 上的 class，也不能只比文件字节**——要验像素/底色。
顺带：截图前要藏掉 Next 的开发浮标（`nextjs-portal`），否则每张证据图右下角都带个黑圆 `N`。

**数据一致性**：演示数据与真实记录**不能拼在同一张卡里**。打卡页曾出现「历史：2 条已分享」
配「0 天连续、12 个空点」——因为 `history` 回退到了演示数据，而连续天数/圆点没有。
凡是「有本地记录就用本地、否则用演示」的地方，**回退单位必须是整块，不是半边**。
