## 一、这一轮到底改了什么

用一句话说：**把"左侧栏"和"会话/消息状态"从对话页搬到了应用外壳**。

改之前，`(console)/page.tsx` 自己渲染 `<Sidebar>`，会话状态也在这一页里；
点「资料库」= 这个页面被卸载 → 侧栏跟着重建。

改之后：

- `(console)/layout.tsx` 外面包了一层 `ChatProvider`（会话域只在这里创建一次）；
- `ConsoleLayout` 成为唯一外壳，所有页面共用**同一个** `<Sidebar>` 实例；
- 对话页不再渲染侧栏，只负责对话区与右栏。

### 1. 会话状态：一个 Provider，两个上下文

```
ChatProvider
├── FullCtx   ← 页面用：messages / streaming / 全部 CRUD
└── RailCtx   ← 侧栏用：sessions / activeSid / loading / CRUD / kbNames
```

为什么拆两个：**"保持挂载" ≠ "不重渲染"**。流式回答每来一个 token 就 setState，
如果侧栏和消息共用一个 context value，它会跟着每秒重算几十次（DOM 不变，CPU 白烧）。
`RailCtx` 的 value 用 `useMemo` 只盯 sessions 那几项，流式期间一次都不变。

侧栏本身用 `memo` 包成 `Rail`，数据只从 `useRailStore()` 取 —— 即使 Provider 重渲染，
它也不会被父级带着重算。

### 2. 外壳：只有一份左栏

`ConsoleLayout` 里原来的 `.console-nav`（196px 网格导航）删掉，换成 `<Sidebar>`：

- 对话页：`.console-shell--chat` 改成 `display:flex`，左栏 + 内容区并排；
- 其它页：`.console-shell` 的网格首列 196px → 240px（≥1600 时 272px），
  和 `layout.css` 里 `.side-left` 的宽度同值。

### 3. 侧栏高度

左栏进了外壳之后成了网格/弹性子项，`height:100%` 在"行高由内容决定"的网格里
会退化成 auto —— 实测 `/knowledge` 时侧栏被内容撑到 **1281px**（视口 860），
整页多出一条纵向滚动、会话列表也不再自己滚。

桌面端（≥900）把它钉成视口高：`height: calc(100dvh - 48px - safe-area)`，
内部列表 `flex-1 + overflow-y:auto`；≤899 仍是 fixed 抽屉，不受这条影响。

### 4. 顺带修的两处

- **导航选中态**：`.side-entry[aria-current="page"]` 的样式 2026-11-15 就写好了，
  但从来没人设过这个属性。现在 `Sidebar` 用 `usePathname()` + `isCurrentNav()` 补上。
- **深色/字号残留**：上一轮删了 UI，这一轮把页面里只为侧栏服务的
  `readTheme/writeTheme/subscribeTheme`、`usageOpen`、`router` 一并清掉，
  免得多留一个"看起来还在用"的消费者。

## 三、值得注意的地方（踩过的坑）

1. **`height:100%` 在网格里不可靠**：网格行高由内容决定时，100% 会退化成 auto。
   要固定高度就显式给 `calc(100dvh - …)`，并同时给 `max-height`。
2. **`memo` 只挡父级重渲染，不挡 context**：`Rail` 之所以能在流式期间不动，
   是因为它订阅的 `RailCtx` 本身不随 token 变，两层缺一不可。
3. **窄屏抽屉是 `position:fixed`**：它不受外壳 `overflow:hidden` 裁切，
   但也不占网格列 —— 移动端断言要看 `transform` 与 `documentElement.scrollWidth`。
4. **Provider 里别直接 `useAuth()`**：那条注释写着"每个实例各查一次 /api/auth/me"，
   放进 `Rail` 会多发一次请求。用户信息由外壳以 props 传下去。
5. **`kbNameMap` 是上浮不是重拉**：页面把 `useKnowledge` 的结果推进 Provider，
   侧栏在别的路由也能显示「资料库 · 名字」，没有新增 `/api/kb` 调用。

1. 嵌入模式不能保留 `.lib-root` 的 `min-height:100dvh` + `overflow-y:auto` —— 外层已经是
   滚动容器，会变成"页中页"双滚动条；`.lib-root--embedded` 把这两条与背景一起撤掉。
2. 嵌入时把 `<main>` 换成 `<div>`：资料库页本身已经是 `<main>`，
   再套一层是无效结构（浏览器会静默纠正，但 DOM 语义就错了）。
