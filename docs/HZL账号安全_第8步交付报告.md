## 1. 本步实际改动

本步没有修改生产业务代码，修改集中在测试适配、隔离工具和交付文档：

1. 将十个旧测试文件中的账号准备改为真实的邮箱发码、验证、注册接口链路。
   测试邮件仅进入内存发送器；保留原有状态码、Cookie、重名、用户名/密码规则、
   会话隔离、查询、打卡、专注、委托、调度等业务断言。
   不增加生产跳过验证的入口；缺邮箱和伪造证明仍由独立注册测试验证拒绝。
2. 完善 tests/registration_support.py：明确初始化本次临时库的账号表，
   防止全量测试切换临时数据库后出现 users 表不存在；仍拒绝真实数据路径。
3. 修正 tools/run_isolated_tests.py 对 SQLite file: URI 的路径识别。
   解码 URI 后仍检查临时目录边界，拒绝远程 URI 和越界路径。
4. 为隔离入口增加 --script 模式，只允许 tests/ 下的 Python 文件；
   在真实业务模块导入之前隔离数据库、数据目录和网络。
   禁止连接现有 8000 业务端口，避免旧脚本误操作可能已经启动的服务。
5. 将 test_web_import_creates_index.py 的硬编码 data 测试文件改放临时目录。
   所有导入、追加、片段数和源代码断言均保留。
6. 新增 tests/test_isolation_tools.py 的八项边界测试。
   合法路径、合法/转义 URI 能实际建表读写；越界/远程 URI 拒绝；
   8000 服务连接拒绝；非测试脚本目标拒绝。
7. 新增配置、接口、显式迁移和回退说明；保存全部测试文件清单及结果证据。

本步没有修复历史前端 lint，没有更改业务校验规则、pytest.ini、skip 或 xfail。
