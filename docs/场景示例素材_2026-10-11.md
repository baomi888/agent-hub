## 一、考研复习（kaoyan）

### 1. 阶段划分（全年）
- 基础期（3–6 月）：英语单词 + 长难句、数学教材过一遍、专业课通读、政治了解结构
- 强化期（7–9 月，黄金期）：专项刷题、英语阅读精刷、开始背政治
- 冲刺期（10–12 月）：真题 + 模考、政治/专业课狂背、调整作息

## 二、课程笔记（notes）

### 1. 康奈尔笔记法（三区页面）
- **笔记区（右，约 70%）**：听课/阅读时记核心要点，用要点列表 + 缩写符号，主次顶格/缩进
- **线索区（左，约 30%）**：课后补写关键词 / 自测问题，用于主动回忆
- **总结区（底部 5–7 行）**：用自己的话总结整页

### 2. 5R 学习法
1. Record 记录：课上在主栏尽量多记有意义的事实与概念
2. Reduce 简化：课后尽快把要点概括进线索区
3. Recite 背诵：遮住主栏，只用线索区提示复述
4. Reflect 思考：建立知识间联系、写体会与疑问
5. Review 复习：每周花约 10 分钟快速回顾

### 3. 让 Agent 帮你做的事（提示词侧已支持）
- 把零散笔记结构化（大纲 → 要点 → 关键词）
- 基于笔记生成概念题 / 选择题 / 简答题并附答案
- 把不同章节知识点连成逻辑线

### 4. 推荐上传结构
- 课程 PPT / 教材章节
- 自己的课堂笔记（文本或图片均可）
- 老师划的重点 / 往年考题

## 三、论文写作（paper）

### 1. IMRaD 标准结构
- 前置：标题 → 作者 → 摘要 → 关键词
- 主体：引言(Introduction) → 方法(Methods) → 结果(Results) → 讨论(Discussion)
- 后置：结论 → 致谢 → 参考文献

### 2. 摘要五句公式
背景句 + However 问题句 + Here 方法句 + We found 结果句 + These findings 意义句
（一般 150–250 词；综述 200–300 词）

### 3. 引言 CARS 模型（Swales）
- Move 1 建立领域：说明研究主题为什么重要
- Move 2 确立缺口：指出已有研究的不足（However / Despite…）
- Move 3 占据缺口：说明本文目的与贡献（The present study aims to…）

### 4. 方法四要素（可复现是核心）
- Who：研究对象、纳入排除标准
- What：材料 / 工具 / 问卷 / 数据集
- How：数据收集与分析步骤
- Why：为何选此法（非主流方法需说明）

### 5. 结果 vs 讨论（最易混）
- Results：只描述事实与数据，不解释、不引文献
- Discussion：解释含义、与前人对比、诚实说明局限、展望未来

### 6. 推荐上传结构
- 导师/领域内的参考文献 PDF（用于规范引用）
- 自己的实验数据 / 调研结果
- 目标期刊的投稿模板与格式要求
