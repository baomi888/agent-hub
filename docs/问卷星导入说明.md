# 问卷星导入说明 · 大学生智能体平台需求问卷（精简版 7 题）

> 配套文件：`问卷星导入_大学生智能体平台需求问卷.txt`（问卷星「文本导入」专用格式）
> 用途：把 7 题问卷一键导入问卷星，免去逐题手建。**预计填写 1–2 分钟，完卷率高。**

---

## 一、导入步骤（约 2 分钟）

1. 打开 [问卷星](https://www.wenjuan.com) → 登录 → 点击「创建问卷」→ 选择「调查」。
2. 进入编辑页后，找顶部/左侧的 **「文本导入」**（或在空白问卷页选择「导入问卷 → 文本导入」）。
3. 把 `问卷星导入_大学生智能体平台需求问卷.txt` 的**全部内容**复制粘贴进文本框。
4. 点击「导入」，问卷星会自动识别题型与选项，生成 7 道题。
5. 检查预览无误后保存。

> 文本格式约定：首行=问卷标题；`数字、题干[题型]`；选项以 `A、B、C…` 开头。
> 题型标记：`[单选题]` / `[多选题]` / `[填空题]`。

---

## 二、导入后需手动设置的 4 处（很重要）

| 题号 | 设置项 | 操作 |
|---|---|---|
| Q1 / Q2 / Q3 / Q4 | **设为必答** | 题干右侧「必答」开关打开（核心决策题，必须填） |
| Q3 | **最多选 5 项** | 题型设置里勾选「最多选择 5 项」（限制多选上限，避免无效票） |
| Q3-K / Q5-I | **允许填空** | 选项「其他」开启「允许填写内容」，收集开放式补充 |
| 文末 | **抽奖/红包** | 问卷设置 → 中奖设置，抽 10 个 20 元红包，进一步提升完卷率 |

> Q5、Q6 非必答但都是秒选多选，实际回收率很高；若想更强制，可一并设为必答。
> Q7 为选填开放题，收集「最想要的功能」作为后续迭代线索。

> 完成后可抽红包，感谢支持 🙏

## 四、数据分析对应（导入后即可跑）

- **Q3 各场景得票率** → 输出「场景需求 Top 榜」，定 MVP 首发模板（选项直接对应模板广场已上线的 8 个模板 + 待验证的 2 个候选「选课/实习」）。
- **学科(Q2) × Q3** → 交叉分析（文科偏论文？工科偏笔记/期末？），验证模板是否在各学科都通用。
- **Q4 各选项占比** → 验证"辅助而非替代"定位的用户接受度；「观望」多则在首页强化理念文案。
- **Q5** → 与发放渠道回收量对照，验证"内容平台+社交分享"获客假设（小红书/B站/抖音/校园墙）。
- **Q6「不动脑」占比** → ≥30% 则产品里强化"教搭建而非代做"的设计。

---

## 五、从问卷到 MVP 的决策规则

- **Q3 得票率前 3 且跨学科普适** → 定为 MVP 首发模板（已在模板广场上线，优先打磨交互）。
- **Q3 中「选课 / 实习聚合」得票高** → 第二轮补充（对应待验证候选）。
- **Q4「马上用」占比高** → 定位成立，直接进入开发；偏低则需先补"看到真实 demo"的信任素材。
- **Q5 高度集中某渠道** → 把后续获客预算压到该渠道。
- **Q6「不动脑」担忧 ≥ 30%** → 在产品首页与每个模板显式强调「辅助而非替代」。
